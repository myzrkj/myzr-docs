- 规格参数（应包括温度参数、支持的系统版本）

**MY-RK3568-L320核心板接口参数**


+--------------+----------+----------+-------------------------------------------------------+
| 接口规格                | 最大可配 | 描述                                                  |
+                         +          +                                                       +
|                         | 置接口数 |                                                       |
+--------------+----------+----------+-------------------------------------------------------+
| 通迅接口     | Ethemet  | 2        | 2路10/100/1000Mbps以太网，支持两个相同的以太网控制器  |
+              +----------+----------+-------------------------------------------------------+
|              | USB2.0   | 2        | 2路USB2.0 HOST                                        |
+              +----------+----------+-------------------------------------------------------+
|              | USB3.0   | 2        | USB3.0xHCI主机控制器,支持1个USB2.0端口和1个超高速端口 |
+              +----------+----------+-------------------------------------------------------+
|              | UART     | 10       | 支持10个UART接口                                      |
+              +----------+----------+-------------------------------------------------------+
|              | PCIE3.0  | 2        | 2路PCIE3.0控制器                                      |
+              +----------+----------+-------------------------------------------------------+
|              | PCIE2.0  | 1        | 1路PCIE2.0控制器                                      |
+              +----------+----------+-------------------------------------------------------+
|              | SATA     | 3        | 3路SATA控制器                                         |
+              +----------+----------+-------------------------------------------------------+
|              | SPI      | 4        | 4路SPI控制器                                          |
+              +----------+----------+-------------------------------------------------------+
|              | 12C      | 6        | 支持6路I2C接口                                        |
+              +----------+----------+-------------------------------------------------------+
|              | I3C      | /        | /                                                     |
+              +----------+----------+-------------------------------------------------------+
|              | CAN      | 3        | 支持3条CAN总线                                        |
+              +----------+----------+-------------------------------------------------------+
|              | PWM      | 16       | 16个基于中断操作的片上PWM(PWM0~PWM15)                 |
+              +----------+----------+-------------------------------------------------------+
|              | ADC      | 8        | 支持8路ADC接口                                        |
+              +----------+----------+-------------------------------------------------------+
|              | I2S      | 3        | 支持3路I2S接口                                        |
+--------------+----------+----------+-------------------------------------------------------+
| 外部存储接口 | SDIO     | 2        | 2路SDIO接口                                           |
+--------------+----------+----------+-------------------------------------------------------+
| 多媒体       | HDMI_TX  | 1        | 支持HDMI1.4和HDMI2.0操作的单物理层PHY                 |
+              +----------+----------+-------------------------------------------------------+
|              | HDMI_RX  | /        | /                                                     |
+              +----------+----------+-------------------------------------------------------+
|              | CSI_MIPI | 2        | 支持2路CSI_MIPI接口                                   |
+              +----------+----------+-------------------------------------------------------+
|              | DSI_MIPI | 1        | 支持1路DSI_MIPI接口                                   |
+              +----------+----------+-------------------------------------------------------+
|              | eDP      | 1        | 支持1路eDP 1.3接口                                    |
+              +----------+----------+-------------------------------------------------------+
|              | LVDS     | 1        | 支持1路LVDS接口                                       |
+              +----------+----------+-------------------------------------------------------+
|              | RGB      | 1        | 支持1路RGB接口                                        |
+--------------+----------+----------+-------------------------------------------------------+
| 软件版本     | Linux    |          | Linux4.19&5.10                                        |
+              +----------+----------+-------------------------------------------------------+
|              | Android  |          | Android11 & 12                                        |
+--------------+----------+----------+-------------------------------------------------------+
