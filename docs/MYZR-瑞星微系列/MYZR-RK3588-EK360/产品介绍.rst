产品介绍

核心板规格
-----------

- 规格参数（应包括温度参数、支持的系统版本）

**MY-RK3588-B360核心板接口参数**

+--------------+----------+------------------+------------------------------------------------------+
| 接口规格                | 最大可配置接口数 | 描述                                                 |
+--------------+----------+------------------+------------------------------------------------------+
| 通迅接口     | Ethemet  | 2                | 2路10/100/1000Mbps以太网，支持两个相同的以太网控制器 |
+              +----------+------------------+------------------------------------------------------+
|              | USB2.0   | 2                | 2路USB2.0 HOST                                       |
+              +----------+------------------+------------------------------------------------------+
|              | USB3.0   | 2                | 支持2个OTG3.1接口和DPTX组合                          |
+              +----------+------------------+------------------------------------------------------+
|              | UART     | 10               | 支持10个UART接口                                     |
+              +----------+------------------+------------------------------------------------------+
|              | PCIE3.0  | 4                | 4路PCIE3.0控制器                                     |
+              +----------+------------------+------------------------------------------------------+
|              | PCIE2.0  | 3                | 3路PCIE2.0控制器                                     |
+              +----------+------------------+------------------------------------------------------+
|              | SATA     | 3                | 3路SATA控制器                                        |
+              +----------+------------------+------------------------------------------------------+
|              | SPI      | 5                | 5路SPI控制器                                         |
+              +----------+------------------+------------------------------------------------------+
|              | 12C      | 9                | 支持9路I2C接口                                       |
+              +----------+------------------+------------------------------------------------------+
|              | I3C      | /                | /                                                    |
+              +----------+------------------+------------------------------------------------------+
|              | CAN      | /                | /                                                    |
+              +----------+------------------+------------------------------------------------------+
|              | PWM      | 16               | 16个基于中断操作的片上PWM(PWM0~PWM15)                |
+              +----------+------------------+------------------------------------------------------+
|              | ADC      | 3                | 支持3路ADC接口                                       |
+              +----------+------------------+------------------------------------------------------+
|              | I2S      | 4                | 支持4路I2S接口                                       |
+--------------+----------+------------------+------------------------------------------------------+
| 外部存储接口 | SDIO     | 1                | 1路SDIO接口                                          |
+--------------+----------+------------------+------------------------------------------------------+
| 多媒体       | HDMI_TX  | 2                | 支持2路HDMI_TX组合接口(但不能同时工作)               |
+              +----------+------------------+------------------------------------------------------+
|              | HDMI_RX  | 1                | 支持1路HDMI_RX接口                                   |
+              +----------+------------------+------------------------------------------------------+
|              | CSI_MIPI | 4                | 支持4路CSI_MIPI接口                                  |
+              +----------+------------------+------------------------------------------------------+
|              | DSI_MIPI | 2                | 支持2路DSI_MIPI接口                                  |
+              +----------+------------------+------------------------------------------------------+
|              | eDP      | 2                | 支持2路eDP 1.3接口                                   |
+              +----------+------------------+------------------------------------------------------+
|              | LVDS     | /                | /                                                    |
+              +----------+------------------+------------------------------------------------------+
|              | RGB      | /                | /                                                    |
+--------------+----------+------------------+------------------------------------------------------+
| 软件版本     | Linux                       | Linux5.10                                            |
+              +----------+------------------+------------------------------------------------------+
|              | Android                     | Android12                                            |
+--------------+----------+------------------+------------------------------------------------------+
