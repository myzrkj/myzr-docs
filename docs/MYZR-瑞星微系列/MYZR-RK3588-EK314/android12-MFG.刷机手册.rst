
刷机手册
========

下载文件
--------

　　打开网盘,下载 “01_烧录” 目录里面的文件


安装DriverAssitant驱动
----------------------

- 解压DriverAssitant_v5.12.zip，后进入DriverAssitant_v5.12文件夹

- 双击DriverInstall.exe程序进行驱动安装

.. figure:: /image/MYZR-瑞星微系列/MYZR-RK3568-EK314/driver-1.png
   :alt: image-driver-1.png



使用RKDevTool进行刷机
-------------------------

- 解压RKDevTool_Release_v2.92.zip，后进入RKDevTool_Release_v2.92文件夹

- 双击RKDevTool.exe，打开程序

- 点击进入“升级固件”界面

.. figure:: /image/MYZR-瑞星微系列/MYZR-RK3568-EK314/RK3568-download-1.png
   :alt: image-RK3568-download-1.png

- 点击“固件”按钮，然后选择相应的update.img镜像文件，镜像文件在刚才下载的image-android11文件下，里面按照不同的显示屏镜像分类

.. figure:: /image/MYZR-瑞星微系列/MYZR-RK3588-EK314/RK3588-download-5.png
   :alt: image-RK3588-download-5.png

.. figure:: /image/MYZR-瑞星微系列/MYZR-RK3588-EK314/RK3588-download-6.png
   :alt: image-RK3588-download-6.png

- 开发板接上烧录线，按住开发板VOL+按键，再给开发板上电，上电3秒左右可看到开发板进入了download模式

.. figure:: /image/MYZR-瑞星微系列/MYZR-RK3588-EK314/RK3588-download-7.png
   :alt: image-RK3588-download-7.png

- 点击“升级”按钮进行刷机，刷成功右边显示成功字符

.. figure:: /image/MYZR-瑞星微系列/MYZR-RK3588-EK314/RK3588-download-8.png
   :alt: image-RK3588-download-8.png
   
- 烧录完成后，开发板系统会自动重启。
