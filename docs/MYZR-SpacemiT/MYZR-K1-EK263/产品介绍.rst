核心板规格
-----------

- 规格参数（应包括温度参数、支持的系统版本）

**MYZR-K1核心板资源表**

+----------+----------------------+------+----------------------------------------------------------------------+
| 接口名称 |                      | 数量 | 描述                                                                 |
+----------+----------------------+------+----------------------------------------------------------------------+
| 通讯接口 | Ethernet             | 2    | 支持2路 10/100/1000 Mbps  RGMII                                      |
+          +----------------------+------+----------------------------------------------------------------------+
|          | USB2.0               | 3    | 支持2路USB2.0 OTG、1路USB2.0 HOST                                    |
+          +----------------------+------+----------------------------------------------------------------------+
|          | USB3.0               | 1    | 支持1路USB 3.0 (combo PCIE PortA)                                    |
+          +----------------------+------+----------------------------------------------------------------------+
|          | UART                 | 10   | 支持10路UART                                                         |
+          +----------------------+------+----------------------------------------------------------------------+
|          | SPI                  | 2    | 支持2路SPI                                                           |
+          +----------------------+------+----------------------------------------------------------------------+
|          | I2C                  | 9    | 支持8路AP_I2C、1路HDMI I2C                                           |
+          +----------------------+------+----------------------------------------------------------------------+
|          | CAN                  | 1    | 支持1路CAN                                                           |
+          +----------------------+------+----------------------------------------------------------------------+
|          | PWM                  | 20   | 支持20路PWM                                                          |
+          +----------------------+------+----------------------------------------------------------------------+
|          | ADC                  | 3    | 支持3路ADC                                                           |
+          +----------------------+------+----------------------------------------------------------------------+
|          | I2S                  | 2    | 支持2路I2S                                                           |
+          +----------------------+------+----------------------------------------------------------------------+
|          | PCIE                 | 3    | 支持1路PCIE PortA Gen2x1、1路PCIE PortB Gen2x2、1路PCIE PortC Gen2x2 |
+----------+----------------------+------+----------------------------------------------------------------------+
| 外部存储 | SDIO                 | 2    | 支持1路SDIO (×1 for WIFI)、支持1路SD (×1 for TF card)                |
+----------+----------------------+------+----------------------------------------------------------------------+
| 多媒体   | CSI                  | 3    | 支持2路4Lane CSI或1路4Lane和2路Lane CSI                              |
+          +                      +      +----------------------------------------------------------------------+
|          |                      |      | 4-Lane + 4-Lane mode                                                 |
+          +                      +      +----------------------------------------------------------------------+
|          |                      |      | 4-Lane + 2-Lane mode                                                 |
+          +                      +      +----------------------------------------------------------------------+
|          |                      |      | 4-Lane + 2-Lane + 2-Lane mode (triple sensor)                        |
+          +----------------------+------+----------------------------------------------------------------------+
|          | DSI                  | 1    | 支持1路4Lane DSI                                                     |
+          +----------------------+------+----------------------------------------------------------------------+
|          | HDMI                 | 1    | 支持1路HDMI TX                                                       |
+----------+----------------------+------+----------------------------------------------------------------------+
| 操作系统 | - Bianbu OS                                                                                        |
+          +----------------------------------------------------------------------------------------------------+
|          | - Linux 主流发型版本                                                                               |
+          +----------------------------------------------------------------------------------------------------+
|          | - RTOS                                                                                             |
+----------+----------------------+------+----------------------------------------------------------------------+
