1 Product Overview
--------------------

1.1 Product Introduction
~~~~~~~~~~~~~~~~~~~~~~~~~~~

|  GW300 is a wireless communication gateway applied in industrial fields. It provides RS485/RS232/100M Ethernet interfaces to realize external device control, data collection, data parsing and transparent transmission. The uplink can access servers or the cloud through 4G and Ethernet to control terminal devices and collect information. The device's temperature rating, static electricity resistance, EMC (Electromagnetic Compatibility), vibration resistance, etc., all meet industrial-grade standards. It can be used in various harsh industrial environments to achieve highly reliable data transmission.

.. figure:: /image/MYZR-其他/网关/GW300/576px-GW300_1.1.0.1_1.png
   :alt: 576px-GW300_1.1.0.1_1.png

|  Device Connection:
|  Ethernet Port: The Ethernet port can be used as a WAN port to connect the gateway to the target network. It can also be configured as a LAN port. 
|  RS232/RS485: Used to connect external devices, supporting data collection, transparent transmission or parsing.

1.2 Product Features
~~~~~~~~~~~~~~~~~~~~~~~

1.2.1 High Hardware Reliability
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

|  The operating temperature range is -20 ~ 75°C, and it supports 12V/24V dual power input. The power supply has protection functions such as reverse connection prevention, pulse group resistance and electrostatic resistance, and the power input can withstand 4KV lightning strikes. The shell is made of 0.8mm high-quality electrolytic aluminum plate and formed by special metal mold stamping. It has an exquisite appearance, as well as good mechanical strength and anti-electromagnetic interference performance. Static surge resistance, EMC, vibration resistance, etc., all meet industrial-grade standards. It adopts a DIN rail mounting method, which is easy to install on-site. The LAN port and RS485 interface ensure transmission reliability in industrial environments. It has a built-in RTC (Real-Time Clock), and the on-board RTC backup battery can work for more than 3 years after power failure, which can meet the application needs of high-performance industrial environments with large amounts of data.

1.2.2 High Performance
~~~~~~~~~~~~~~~~~~~~~~~~~

|  The product adopts a Cortex-A7 dual-core processor with a main frequency of up to 1.2GHz.

1.2.3 4G Network Access
~~~~~~~~~~~~~~~~~~~~~~~~~~

|  It has a built-in 4G all-network module, supporting 4G networks with high speed, low latency, high reliability and low-power massive connections. It supports network standards such as LTE FDD and LTE TDD to achieve full coverage.

1.2.4 Rich Data Communication Interfaces
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

|  RS485 Interface: 1 RS485 interface, supporting 4KV lightning protection
|  RS232 Interface: 1 RS232 interface, supporting 4KV lightning protection
|  Ethernet Port: 1 100M Ethernet interface, supporting 4KV lightning protection
