启动手册
========

串口线的连接
~~~~~~~~~~~~

#. 把串口线的一端连接到开发板的“P2”口，另一端连接到电脑的串口或USB口。

#. 参考《Xshell 参考手册》新建串口会话并打开会话。

网线的连接
~~~~~~~~~~

把网线的一端连接到"U17"或"U19"，另一端连接到电脑的网口。

下载线的连接
~~~~~~~~~~~~

把 type-c 数据线的一端连接"U9"，另一端连接到电脑的后置USB口。

启动开发板
----------

检查开发板的启动模式拨码
~~~~~~~~~~~~~~~~~~~~~~~~

把开发板的 "SW1" 拨码开关拨到启动模式。

为开发板上电
~~~~~~~~~~~~

把电源适配器的一端连接到开发板的“J1”，另一端插入到市电（220V的交流电）插座。

开发板登录
----------

启动系统完后输出imx93evk login: 时，可以登录：

【用户名】 ：root

【密码】 ：无

提示：登录后可以通过“passwd”命令来设置和修改密码。
