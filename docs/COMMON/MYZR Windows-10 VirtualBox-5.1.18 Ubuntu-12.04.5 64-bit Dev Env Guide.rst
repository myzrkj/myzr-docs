File Download

**Virtual machine software**

 | Location: MYZR-Universal Resources -> Virtual Machine Software and Systems -> VirtualBox-5.1.18

- Ubuntu-12.04.5

Virtual Machine Software Installation
----------------------------------------

|   Open the downloaded “VirtualBox-5.1.18” folder and double-click “VirtualBox-5.1.18-114002-Win.exe”，to refer to “01_VB5118_Installation” for installation.

Configure for virtual machines Windows
------------------------------------------

**Add Windows Network Card**

 | Open the downloaded “VirtualBox-5.1.18”folder, refer to “03_WIN10_LoopbackAdapterAdd” ，and add Loopback Adder to Windows.

**Configure Windows Network Card**

 | Open the “VirtualBox-5.1.18” folder that you downloaded. Go to “04_WIN10_LoopbackAdapterSettings” ，to configure the LoopbackAdapter on Windows.

**Import Virtual Machine System**

 | Open the downloaded "VirtualBox-5.1.18" folder and import the virtual machine system to VirtualBox with reference to "07 _ VB5118 _ Impact VirtualAppeal".

Virtual Machine Settings
---------------------------

 | Open the downloaded 'VirtualBox-5.1.18' folder and configure the virtual machine with reference to '08-VB5118-VirtualMachineSettings'.
