MYZR Windows-7 VirtualBox-4.3.40 Ubutnu-12.04.5 64位开发环境指导
===================================================================

文件下载
~~~~~~~~~

|  打开网站： **wiki.myzr.com.cn** ，点击 **MYZR 通用资源** 。 **虚拟机软件及系统：** 打开网盘到 **MYZR-COMMON-20181007 -> 1.1_虚拟机软件及系统** ，下载 **VirtualBox-4.3.40** 目录。

虚拟机软件安装
~~~~~~~~~~~~~~

|  打开下载的 **VirtualBox-4.3.40** 文件夹，双击 **VirtualBox-4.3.40-110317-Win.exe**，参照 **01_VB4340_Installation** 安装。

为虚拟机配置 Windows
~~~~~~~~~~~~~~~~~~~~~

**添加 Windows 网卡**

|  打开下载的 VirtualBox-4.3.40 文件夹，参照 03_WIN7_LoopbackAdapterAdd，把 Loopback Adapter 添加到 Windows。

**配置 Windows 网卡**

|  打开下载的 VirtualBox-4.3.40 文件夹，参照 04_WIN7_LoopbackAdapterSettings，在 Windows 下配置 Loopback Adapter。

**导入虚拟机系统**

|  打开下载的 VirtualBox-4.3.40 文件夹，参照 07_VB4340_ImportVirtualAppliance，把虚拟机系统导入到 VirtualBox。

虚拟机设置
~~~~~~~~~~~

|  打开下载的 VirtualBox-4.3.40 文件夹，参照 08_VB4340_VirtualMachineSettings，配置好虚拟机。
