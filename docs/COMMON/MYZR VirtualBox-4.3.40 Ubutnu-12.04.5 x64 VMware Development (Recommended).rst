Download relevant resources
-----------------------------

**Software of virtual machine**

|   Download in network disk “VirtualBox-4.3.40”. File location is MYZR-general resource->Virtual machine system->VirtualBox-4.3.40.

**System of virtual machine**

|   Download in network disk “vb43-u12045-serv-amd64.ova”.File location is MYZR-general resource->Virtual machine system-> vb43-u12045-serv-amd64.ova.

Installation & configuration of virtual machine
--------------------------------------------------

**Software installation of virtual machine**

|   Open the folder “VirtualBox-4.3.40”，double click “VirtualBox-4.3.40-110317-Win.exe",refer “01.VirtualBox-4.3.40 install screenshot”.

**Add Windows network card for virtual machine**

|   Open downloaded “VirtualBox-4.3.40” folder，refer to “02.add local looback adaptor（WIN7）” ，add local looback adaptor to Windows.

**Configure virtual machine with Windows network card**

|   Open VirtualBox-4.3.40” folder downloaded，refer to “03.cofiguration of local looback adaptor（WIN7）” ，configure local looback adaptor under Windows.

**Import Virtual machine system**

|   Open the folder “VirtualBox-4.3.40”,refer“02.VirtualBox-4.3.40 import virtual machine ”import“vb43-u12045-serv-amd64.ova”

**Configure virtual machine with network card**

|   Open “VirtualBox-4.3.40” folder downloaded，refer to “05.network configuration for virtual machine” ，configure network for virtual machine.
