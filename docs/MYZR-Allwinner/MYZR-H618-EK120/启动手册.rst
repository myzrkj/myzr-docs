启动手册
==========

快速启动
-----------

一、核心接口说明：
~~~~~~~~~~~~~~~~~~

  1. 电源

    - J1：Type-C电源输入（5V）
    - LED指示灯：
      - LED2（红色）：电源指示灯 - 常亮表示供电正常
      - LED1（绿色）：系统指示灯 - 闪烁表示系统运行中

  2. 调试（靠近USB端口）

    - DEBUG：Type-C串口（靠近USB接口）
    - 波特率：115200bps

二、连接指南
~~~~~~~~~~~~~~

|   串口连接

1. 准备USB-A转Type-C数据线 
2. Type-C端插入开发板"DEBUG"口  
3. USB-A端插入电脑主机后置USB口（避免前置供电不足）  

连接后使用Xshell或者MobaXterm等终端软件打开相应COM接口。
电源连接（J1接口接5V type-C数据线作为电源供应）
注意：H618有两种启动方式，emmc启动或者SD卡启动，在启动前确保相应启动方式有放置正确的镜像。
若使用SD卡启动系统，请将烧录好系统的SD卡插入到开发板SD卡槽再进行开发板上电，SD卡首次启动时间会比较长。

- 连接验证：

|   上电后观察：

 | 红色LED2 常亮 → 电源输入正常
 | 绿色LED1 未亮 → 等待系统启动（约3秒后开始闪烁）

- HDMI连接规范：

1. 使用HDMI 线缆
2. 开发板J5 → 显示器主输入口（避免扩展坞转接）  
3. 显示器设置：

 - 输入源：HDMI 1  
 - 分辨率：1920×1080@60Hz（首选） 

串口信息解读
~~~~~~~~~~~~~

|   U-Boot段示例：

 | [02.573]DRAM:  2 GiB                    # 内存容量检测
 | [02.608]CPU=1008 MHz                    # CPU主频锁定
 | Hit any key to stop autoboot: 0          # 3秒等待中断窗口

|   内核段示例：

 | Linux version 5.4.125 #1 SMP Mon Aug 11 15:24:10 CST 2025
 | Machine model: MYZR-H618-EK120-v2        # 设备树匹配成功
 | [    0.000000] cma: Reserved 16 MiB at 0xbf000000 # 内存保留区

三、系统交互指南
~~~~~~~~~~~~~~~~~

|   启动完成后，串口终端显示：

 | myzr-h618-ek120 login: myzr (automatic login)

|   输入默认凭证：

 | 用户名：myzr
 | 密码：myzr（已设置开机自动登录）
  
|   若使用root用户登录：
    
 | 用户名：root
 | 密码：root
