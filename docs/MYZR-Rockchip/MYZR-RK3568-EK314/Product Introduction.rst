| **Product Introduction:**
| 　• **MYZR RK3568 Development Board** (MYZR-RK3568-EK314) enables customers to conveniently evaluate the MYZR-RK3568-CB314 core board, providing a foundation and reference for customers to design their own hardware.
| 　• **MYZR RK3568 Core Board** (MYZR-RK3568-CB314) The Rockchip RK3568 chip is a mid-to-high-end general-purpose SOC. It offers a number of powerful embedded hardware engines to optimize the performance of high-end applications.

| **Target Applications:**
| 　• **Smart Home:** AI local servers, alarm and security systems, intelligent robots, network nodes, control, home medical monitoring, speakers, AV receivers, and other home automation applications.
| 　• **Smart City:** Safety and security, monitoring systems, people flow and traffic management, fleet management.
| 　• **Smart Scenarios:** Smart retail, POS terminals, targeted advertising, building control, web conference systems, medical diagnosis.
| 　• **Industrial Internet of Things:** Machine learning, robot control, industrial gateways, HMI and computers, commercial printers and scanners, industrial tablets, intelligent industrial cameras, and various other industrial automation applications.

| **Main Features:**
| 　• **Multi-core High-performance Processor:** Based on quad-core Arm® Cortex®-A55 with a main frequency of up to 2.0GHz, and integrated with a neural network acceleration unit (NPU) providing 1TOPS of computing power.
| 　• **Image Signal Processor (ISP):** Based on an image processing unit (ISP) and camera interface, with 8M@30fps processing capability, powerful HDR function, and support for distortion correction, defogging, noise elimination, etc.
| 　• **Video Processing and H.265 Encoding:** Supports 4K H.264/H.265/VP9 and other formats of high-definition decoding, and supports 1080p 60fps H.264 and H.265 encoding.
| 　• **High-performance External Memory Interface:** Supports DDR3/DDR3L/DDR4/LPDDR3/LPDDR4/LPDDR4X.
| 　• **Rich Display Interfaces:** Built-in HDMI/eDP/LVDS/MIPI/ and other interfaces, supporting multi-display.
| 　• **Rich Communication Interfaces:** Supports USB2.0/USB3.0/PCIE3.0/PCIE2.1/SATA3.0/QSGMII.
| 　• **Industry 4.0:** Integrates multiple high-speed buses to empower Industry 4.0 applications. Gigabit Ethernet provides real-time and synchronous control based on Ethernet connection.
