Flashing the Firmware
=======================

Installing the DriverAssitant Driver
--------------------------------------

- Find the Rockchip USB driver installation package in the downloaded network disk materials. The path is: 3. Software Materials --> 3.2 - Tools --> DriverAssitant_v5.13.zip
- Extract DriverAssitant_v5.13.zip and enter the extracted DriverAssitant_v5.13 folder
- Double - click the DriverInstall.exe program to install the driver. The installation steps are as follows:

Using the RKDevTool for Flashing
----------------------------------

- Find the RKDevTool driver installation package in the downloaded network disk materials. The path is: 3. Software Materials --> 3.2 - Tools --> RKRKDevTool_v3.30_for_window.zip
- Extract RKDevTool_v3.30_for_window.zip and enter the extracted RKDevTool_v3.30_for_window folder
- Double - click RKDevTool.exe to open the program

.. figure:: /image/MYZR-瑞芯微系列/MYZR-RK3576-EK288/刷新固件5.png
   :alt: 刷新固件5.png
   :width: 60%

**Full Flash**

- Click to enter the "Upgrade Firmware" interface

.. figure:: /image/MYZR-瑞芯微系列/MYZR-RK3576-EK288/刷新固件6.png
   :alt: 刷新固件6.png
   :width: 60%

- Click the "Firmware" button, then select the corresponding img image file

.. figure:: /image/MYZR-瑞芯微系列/MYZR-RK3576-EK288/刷新固件7.png
   :alt: 刷新固件7.png
   :width: 60%

.. figure:: /image/MYZR-瑞芯微系列/MYZR-RK3576-EK288/刷新固件8.png
   :alt: 刷新固件8.png
   :width: 60%

- Connect the development board with the flashing cable, press and hold the K1 button on the development board, then power on the development board. After about 3 seconds of power - on, you can see that the development board has entered the LOADER mode

.. figure:: /image/MYZR-瑞芯微系列/MYZR-RK3576-EK288/刷新固件9.png
   :alt: 刷新固件9.png
   :width: 60%

- Click the "Upgrade" button to start flashing. When the flashing is successful, the success message will be displayed on the right

.. figure:: /image/MYZR-瑞芯微系列/MYZR-RK3576-EK288/刷新固件10.png
   :alt: 刷新固件10.png
   :width: 60%

- After the flashing is completed, power on the development board again.

**Single or Multiple Flashes**

- Connect the development board with the flashing cable, press and hold the K1 button on the development board, then power on the development board. After about 3 seconds of power - on, you can see that the development board has entered the LOADER mode

.. figure:: /image/MYZR-瑞芯微系列/MYZR-RK3576-EK288/刷新固件11.png
   :alt: 刷新固件11.png
   :width: 60%

- Then keep clicking "OK"
