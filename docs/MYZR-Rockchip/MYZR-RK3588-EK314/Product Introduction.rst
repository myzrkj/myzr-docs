| **Product Introduction:**
| 　• **Mingyuan Zhirui RK3588 Development Board** (MYZR-RK3588-EK314) enables customers to conveniently evaluate the MYZR-RK3588-CB314 core board, providing a foundation and reference for customers to design their own hardware independently.
| 　• **Mingyuan Zhirui RK3588 Core Board** (MYZR-RK3588-CB314): The Rockchip RK3588 chip is a mid-to-high-end general-purpose SOC. Adopting an advanced 8nm process, it features an 8-core 64-bit architecture, boasting high performance, low power consumption, powerful AI computing power, and video encoding/processing capabilities.

| **Target Applications:**
| 　• **Smart Home:** AI local servers, alarm and security systems, smart robots, network nodes, control devices, home medical monitoring equipment, speakers, AV receivers, and other home automation applications.
| 　• **Smart City:** Security and safety protection, monitoring systems, crowd and traffic management, fleet management.
| 　• **Smart Scenarios:** Smart retail, POS terminals, targeted advertising, building control, web conferencing systems, medical diagnosis.
| 　• **Industrial IoT:** Machine learning, robot control, industrial gateways, HMI (Human-Machine Interface) and computers, commercial printers and scanners, industrial tablets, smart industrial cameras, and various other industrial automation applications.

| **Key Features:**
| 　• **Multi-Core High-Performance Processor:** 8-core 64-bit big.LITTLE architecture, 4*Cortex-A76 + 4*Cortex-A55. Maximum frequency up to 2.4GHz.
| 　• **Powerful AI Computing Power (NPU):** 6TOPS computing power, triple-core architecture, supporting int4/int8/int16/FP16/BF16/TF32.
| 　• **Image Signal Processor (ISP):** Equipped with an Image Signal Processor (ISP) and camera interface, supporting 32MP processing capability, powerful HDR and 3DNR functions, as well as distortion correction, defogging, noise reduction, and other features.
| 　• **Video Processing and H.265 Encoding:** Supports high-definition decoding of multiple formats such as 4K H.264/H.265/VP9, and supports encoding of H.264 and H.265 formats at 1080p 60fps.
| 　• **High-Performance External Memory Interface:** Supports DDR3/DDR3L/DDR4/LPDDR3/LPDDR4/LPDDR4X/LPDDR5.
| 　• **Rich Display Interfaces:** Built-in interfaces including HDMI/VGA/TYPE-C/MIPI/, supporting multi-display.
| 　• **Rich Communication Interfaces:** Supports USB2.0/USB3.0/PCIE3.0/PCIE2.1/SATA3.0/QSGMII.
| 　• **Industry 4.0:** Integrates multiple high-speed buses to empower Industry 4.0 applications. Gigabit Ethernet provides real-time and synchronous control based on Ethernet connection.
