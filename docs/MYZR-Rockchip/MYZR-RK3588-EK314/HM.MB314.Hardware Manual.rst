Interface Functions
---------------------

Main Power Input
~~~~~~~~~~~~~~~~~~

|  Silkscreen: J1  
|  Interface Attribute: Power supply - Center-positive, outer-negative jack   
|  Voltage: 12V   
|  Current: 3A and above   

Reset
~~~~~~~~

|  Silkscreen: RESET  
|  Function: Reset

   :alt: image-RK3588-复位

Wake-Up
~~~~~~~~~~

|  Silkscreen: PWR  
|  Interface Attribute: Sleep wake-up

~~~~~~~~~~~~~~~~~~~~~~~

|  Silkscreen: J22  
|  Interface Attribute: TTL-level debug serial port; a TTL to USB module is required for connection to a computer

TF
~~~~

|  Silkscreen: J5 
|  Interface Attribute: Standard spring-loaded TF card socket


RTC
~~~~~

|  Silkscreen: U8, BT1  
|  Interface Attribute: I2C communication real-time clock; a button battery is required for use
