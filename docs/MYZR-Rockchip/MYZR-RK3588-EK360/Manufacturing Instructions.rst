Manufacturing Instructions
============================

**Backplane Package**

| It is strongly recommended that the package of the backplane adopts the design package of the reference board without any modifications. This package has undergone multiple verifications and features strong solderability.

**Stencil for Backplane**

| Since the backplane is equipped with fine-pitch board-to-board connectors, it is recommended to use a 0.1mm-thick solder paste stencil for the backplane. The solder paste should adopt a lead-free process, and the reflow oven temperature profile can be referenced to the solder paste profile.
