测试说明：控制LED亮灭进行测试

测试操作：

执行如下命令控制LED4灭

.. code-block:: shell

   echo 0 > /sys/class/leds/heartbeat/brightness

执行如下命令控制LED4亮

.. code-block:: shell

   echo 1 > /sys/class/leds/heartbeat/brightness

.. code-block:: shell

.. code-block:: shell

   echo 0 > /sys/class/leds/disk/brightness

网口测试
--------

网口1
~~~~~

接口丝印：J13

系统接口：eth0

测试说明：采用开发板向PC发送ICMP报文的方式进行测试

测试操作：

* 配置电脑有线网卡IP为 192.168.137.99

* 使用网线连接开发板网口和电脑的网口，串口显示信息：

.. code-block:: shell

   [  275.170629] rk_gmac-dwmac fe1c0000.ethernet eth0: Link is Up - 1Gbps/

* 查看开发板网口1信息，输入指令如下：

.. code-block:: shell

   ifconfig eth0

* 配置网口1的IPV4 IP，输入指令如下：

.. code-block:: shell

   ifconfig eth0 192.168.137.81 netmask 255.255.255.0

* 再次查看开发板网口1信息，确认 IPv4 地址是否成功配置，如未成功配置请从步骤4开始重新执行操作，输入指令如下：

.. code-block:: shell

   ifconfig eth0

* 输入指令如下进行验证网口1：

.. code-block:: shell

   ping -I eth0 192.168.137.99 -c 2 -w 4

“0% packet loss”表示测试通过

如果出现”100% packet loss”，请先确认电脑的防火墙是否全部关闭

背光测试
--------

背光的亮度设置范围为（0--255），255表示亮度最高，0表示关闭背光亮度。进入系统后在终端输入如下命令进行背光测试。

输入以下命令查看当前屏幕背光值

.. code-block:: shell

   cat /sys/class/backlight/ffb10000.dsi.0/brightness

输出信息类似如下：

.. code-block:: shell

   200

输入以下命令设置背光熄灭

.. code-block:: shell

   echo 0 > /sys/class/backlight/ffb10000.dsi.0/brightness

.. code-block:: shell

   echo 200 > /sys/class/backlight/ffb10000.dsi.0/brightness

MIPI CSI 接口测试
-----------------

接口丝印：J5、J6

测试说明：使用摄像头并在显示器上播放摄像头画面进行测试

测试操作：

1、将摄像头通过软排线和开发板上对应接口连接，注意不要接反。

2、将网盘中 camera 目录下的脚本文件和 ISP 参数文件拷贝至开发板对应目录下。

.. code-block:: shell

   # 1.通过adb将⽂件导⼊开发板
   adb push ov13850_RK-CMK-8M-2-v1_CK8401.json/etc/iqfiles
   adb push two_camera_ov13850.sh /
   
   # 2.进⾏转换字符并重启
   dos2unix /etc/iqfiles/ov13850_RK-CMK-8M-2-v1_CK8401.json
   reboot
   
   # 赋予权限并执⾏脚本
   chmoda+xtwo_camera_ov13850.sh
   ./two_camera_ov13850.sh
