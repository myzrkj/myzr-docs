产品介绍

核心板介绍
----------

硬件资源
~~~~~~~~

MYZR-RK3562核心板集成RK3562处理器、DDR存储、电源管理、时钟及高速接口电路，可快速嵌入终端产品设计。

处理器内部集成：

* RK3562处理器

* LPDDR4X内存

* SPI NAND Flash

* PMIC电源管理

* 千兆网络接口

* USB3.0 OTG

* MIPI显示接口

* MIPI摄像头接口
