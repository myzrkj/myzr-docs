产品介绍
==========

核心板介绍
----------

硬件资源
~~~~~~~~

MYZR-RK3568核心板采用LGA盲埋沉金工艺设计，将RK3568处理器、电源管理、存储器等核心电路集成于单板，使其体积做到极致，方便用户进行各类小型化的产品开发。

核心板内部集成：

* RK3568处理器

* DDR内存

* eMMC Flash

* PMIC电源管理

* 时钟电路

* 启动配置电路

开发板各模块电路设计说明
------------------------

1. 电源电路
~~~~~~~~~~~

采用5V DC输入，通过PMIC产生：

* VDD_CPU

* VDD_LOGIC

* VCC_IO

* DDR电源

2. 启动配置电路
~~~~~~~~~~~~~~~

通过BOOT配置电阻设置启动模式。

3. 复位电路
~~~~~~~~~~~

提供独立RESET按键。

4. 存储电路
~~~~~~~~~~~

支持：

* eMMC

* TF Card

5. 网络电路
~~~~~~~~~~~

千兆以太网PHY设计。

6. 显示电路
~~~~~~~~~~~

支持： HDMI

* MIPI DSI

* LVDS
