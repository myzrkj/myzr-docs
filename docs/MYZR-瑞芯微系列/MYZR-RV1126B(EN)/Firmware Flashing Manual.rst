Firmware Flashing Manual
==========================

Firmware Flashing Using USB to Type-C Data Cable
---------------------------------------------------

1. Use a USB to Type-C data cable to connect the development board and the PC. Connect the Type-C end of the cable to the OTG interface of the development board, and the USB end of the cable to the USB interface of the PC.
2. Extract the DriverAssitant_v5.13.zip compressed package, enter the extracted folder, find the DriverInstall.exe program, and double-click to install it.

.. image:: /image/MYZR-瑞芯微系列/MYZR-RV1126B/刷机手册1.png
   :alt: 刷机手册1.png

3. Extract the RKDevTool_Release_v3.15.zip compressed package, enter the extracted folder, find the RKDevTool.exe program, and double-click to open it.

.. image:: /image/MYZR-瑞芯微系列/MYZR-RV1126B/刷机手册2.png
   :alt: 刷机手册2.png

4. Full Firmware Flashing

|   After double-clicking to open the RKDevTool.exe program, click "Upgrade Firmware", then click the "Firmware" button to select the corresponding img file. Click the "Switch" button to switch the mode to "LOADER" mode, then click the "Upgrade" button. Check the characters on the right; if "Firmware Download Successful" is displayed, the flashing is successful.
