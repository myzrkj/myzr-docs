Product Introduction
====================

Core Board Introduction
-----------------------

Hardware Resources
~~~~~~~~~~~~~~~~~~

The MYZR-RK3562 core board integrates the RK3562 processor, DDR storage, power management, clock, and high-speed interface circuits, enabling rapid integration into terminal product designs.

Processor internal integration:

* RK3562 Processor

* LPDDR4X Memory

* SPI NAND Flash

* PMIC Power Management

* Gigabit Network Interface

* USB3.0 OTG

* MIPI Display Interface

* MIPI Camera Interface
