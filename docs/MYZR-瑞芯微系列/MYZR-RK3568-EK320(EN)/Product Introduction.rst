Core Board Specifications

**MY-RK3568-L320 Core Board Interface Parameters**


+-----------------------------+----------+--------------------------+---------------------------------------------------------------------------------------+
| Interface Specification     |          | Max Config Interface Cnt | Description                                                                           |
+-----------------------------+----------+--------------------------+---------------------------------------------------------------------------------------+
| Communication Interfaces    | Ethernet | 2                        | 2 channels of 10/100/1000Mbps Ethernet, supporting two identical Ethernet controllers |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | USB2.0   | 2                        | 2 channels of USB2.0 HOST                                                             |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | USB3.0   | 2                        | USB3.0 xHCI host controller, supporting 1 USB2.0 port and 1 super-speed port          |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | UART     | 10                       | Supports 10 UART interfaces                                                           |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | PCIE3.0  | 2                        | 2 channels of PCIE3.0 controllers                                                     |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | PCIE2.0  | 1                        | 1 channel of PCIE2.0 controller                                                       |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | SATA     | 3                        | 3 channels of SATA controllers                                                        |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | SPI      | 4                        | 4 channels of SPI controllers                                                         |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | I2C      | 6                        | Supports 6 channels of I2C interfaces                                                 |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | I3C      | /                        | /                                                                                     |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | CAN      | 3                        | Supports 3 CAN buses                                                                  |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | PWM      | 16                       | 16 on-chip PWMs (PWM0~PWM15) based on interrupt operation                             |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | ADC      | 8                        | Supports 8 channels of ADC interfaces                                                 |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | I2S      | 3                        | Supports 3 channels of I2S interfaces                                                 |
+-----------------------------+----------+--------------------------+---------------------------------------------------------------------------------------+
| External Storage Interfaces | SDIO     | 2                        | 2 channels of SDIO interfaces                                                         |
+-----------------------------+----------+--------------------------+---------------------------------------------------------------------------------------+
| Multimedia                  | HDMI_TX  | 1                        | Single physical layer PHY supporting HDMI1.4 and HDMI2.0 operation                    |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | HDMI_RX  | /                        | /                                                                                     |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | CSI_MIPI | 1                        | Supports 1 channel of 4-lane CSI_MIPI interface                                       |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | DSI_MIPI | 2                        | Supports 2 channels of 4-lane DSI_MIPI interface                                      |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | eDP      | 1                        | Supports 1 channel of eDP 1.3 interface                                               |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | LVDS     | 1                        | Supports 1 channel of LVDS interface                                                  |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | RGB      | 1                        | Supports 1 channel of RGB interface                                                   |
+-----------------------------+----------+--------------------------+---------------------------------------------------------------------------------------+
| Software Versions           | Linux    |                          | Linux4.19 & 5.10                                                                      |
+                             +----------+--------------------------+---------------------------------------------------------------------------------------+
|                             | Android  |                          | Android11 & 12                                                                        |
