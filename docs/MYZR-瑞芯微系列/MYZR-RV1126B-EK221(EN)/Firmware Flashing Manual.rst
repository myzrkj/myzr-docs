Firmware Flashing Manual
==========================

Download and Install DriverInstall Driver
--------------------------------------------

1. Locate the DriverAssitant_v5.13.zip compressed package from the network disk driver.
2. Extract the package and enter the DriverAssitant_v5.13 folder.
3. Double-click the DriverInstall.exe program to install the driver. The installation steps are as shown below.

Flash Firmware Using USB to Type-C Data Cable
------------------------------------------------

1. Use a USB to Type-C data cable to connect the development board and the PC. Connect the Type-C end of the data cable to the OTG interface of the development board, and the USB end of the data cable to the USB interface of the PC.
2. Extract the DriverAssitant_v5.13.zip compressed package, enter the extracted folder, locate the DriverInstall.exe program, and double-click to install it.

.. image:: /image/MYZR-瑞芯微系列/MYZR-RV1126B-EK221/刷机5.png
   :alt: 刷机5.png

3. Extract the RKDevTool_Release_v3.15.zip compressed package, enter the extracted folder, locate the RKDevTool.exe program, and double-click to open it.

.. image:: /image/MYZR-瑞芯微系列/MYZR-RV1126B-EK221/刷机6.png
   :alt: 刷机6.png

4. Full Firmware Flashing

|  After double-clicking to open the RKDevTool.exe program, click "Upgrade Firmware", then click the "Firmware" button to select the corresponding img file. Click the "Switch" button to switch the mode to "LOADER" mode, then click the "Upgrade" button. Check the characters on the right; if it displays "Firmware download successful", the flashing is successful.
