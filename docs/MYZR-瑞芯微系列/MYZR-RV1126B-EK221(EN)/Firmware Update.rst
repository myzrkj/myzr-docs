Firmware Update
===============

Install DriverAssitant Driver
----------------------------

* Find the Rockchip USB driver installation package from the downloaded cloud materials, path: 3.Software Materials --> 3.2-Tools --> DriverAssitant_v5.11.zip

* Extract DriverAssitant_v5.11.zip and enter the DriverAssitant_v5.11 folder

* Double-click DriverInstall.exe to install the driver. Follow these steps:

Flash Firmware Using RKDevTool
------------------------------

* Find the RKDevTool installation package from the downloaded cloud materials, path: 3.Software Materials --> 3.2-Tools --> RKDevTool_Release_v3.15.zip

* Extract RKDevTool_Release_v3.15.zip and enter the RKDevTool_Release_v3.15 folder

* Double-click RKDevTool.exe to launch the program

.. image:: ../../../image/MYZR-瑞芯微系列/MYZR-RV1126B-EK221/使用RKDevTool工具进行刷机.png
   :alt: Flash Firmware Using RKDevTool
   :width: 100%

* Click to enter the "Upgrade Firmware" interface

.. image:: ../../../image/MYZR-瑞芯微系列/MYZR-RV1126B-EK221/使用RKDevTool工具进行刷机_02.png
   :alt: Flash Firmware Using RKDevTool
   :width: 100%

* Click the "Firmware" button, then select the corresponding img image file

.. image:: ../../../image/MYZR-瑞芯微系列/MYZR-RV1126B-EK221/使用RKDevTool工具进行刷机_03.png
   :alt: Flash Firmware Using RKDevTool
   :width: 100%

.. image:: ../../../image/MYZR-瑞芯微系列/MYZR-RV1126B-EK221/使用RKDevTool工具进行刷机_04.png
   :alt: Flash Firmware Using RKDevTool
   :width: 100%

.. image:: ../../../image/MYZR-瑞芯微系列/MYZR-RV1126B-EK221/使用RKDevTool工具进行刷机_05.png
   :alt: Flash Firmware Using RKDevTool
   :width: 100%

* Connect the flashing cable to the development board, press and hold the SW8 button on the board, then power on the board. After about 3 seconds, you can see the board enter download mode

.. image:: ../../../image/MYZR-瑞芯微系列/MYZR-RV1126B-EK221/使用RKDevTool工具进行刷机_06.png
   :alt: Flash Firmware Using RKDevTool
   :width: 100%

* Click the "Upgrade" button to flash the firmware. When successful, "Success" will be displayed on the right

.. image:: ../../../image/MYZR-瑞芯微系列/MYZR-RV1126B-EK221/使用RKDevTool工具进行刷机_07.png
   :alt: Flash Firmware Using RKDevTool
   :width: 100%

* After flashing is complete, power cycle the development board.
