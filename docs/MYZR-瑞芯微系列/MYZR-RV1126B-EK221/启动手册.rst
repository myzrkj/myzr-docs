TTL串口模块接法
~~~~~~~~~

开发板没有拨码

下载线的连接
~~~~~~

把Type-C线的一端连接OTG ,另一端连接到电脑的后置USB口。

电源线的连接
~~~~~~

把12V-2A电源适配器的一端连接到开发板的“CON1”,另一端插入到市电(220V的交流电)插座。

启动开发板
-----

为开发板上电
~~~~~~

将开发板的开关电源“POW_KEY”拨到“ON”一侧,以使开发板电源开关打开。
