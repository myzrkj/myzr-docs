使用 USB 转 Type-C 数据线刷机
------------------------------

1. 使用 USB 转 Type-c 数据线连接开发板和 PC 机，将数据线的 Type-c 端连接开发板的 OTG 接口，数据线的 USB 端连接 PC 机的 USB 接口。
2. 解压 DriverAssitant_v5.13.zip 压缩包，进入解压后的文件夹，找到 DriverInstall.exe 程序，双击安装。

.. image:: /image/MYZR-瑞芯微系列/MYZR-RV1126B/刷机手册1.png
   :alt: 刷机手册1.png

3. 解压 RKDevTool_Release_v3.15.zip 压缩包，进入解压后的文件，找到 RKDevTool.exe 程序，双击打开。

.. image:: /image/MYZR-瑞芯微系列/MYZR-RV1126B/刷机手册2.png
   :alt: 刷机手册2.png

4. 全局烧录

|   双击打开 RKDevTool.exe 程序后，点击“升级固件”，然后点击“固件”按钮，选择相应的 img 文件，点击“切换”按钮，将模式切换到“LOADER”模式，点击“升级”按钮，查看右边字符，显示“下载固件成功”则烧入成功。
