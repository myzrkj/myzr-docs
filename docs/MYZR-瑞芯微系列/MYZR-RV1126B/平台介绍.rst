平台介绍
=========

产品简介
----------

- CPU：搭载四核 ARM Cortex - A53，主频可达 1.5GHz，性能达同档位芯片 2 倍以上。此外，还集成了一个 300MHz 的 RISC - V MCU，用于一些低功耗、实时性要求较高的任务。
- NPU：内置自研 NPU，算力高达 3Tops，支持 INT8/INT16/FP16 等数据类型，以及权重稀疏化、W4A16/W8A16 混合精度量化及 Transformer 优化技术，可流畅运行 2B 以内参数规模的大语言模型与多模态模型。
- 内存：支持 32bit 的 DDR3/DDR3L/LPDDR3/DDR4/LPDDR4 内存，还支持 eMMC 4.51、SPI Flash、Nand Flash 等存储设备，并且支持快速启动。
- 显示：具备 MIPI - DSI/RGB 接口，最高可支持 1080P60fps 的显示输出，同时集成 2D 图形引擎，支持图像的旋转、镜像、缩放等操作。
- 多媒体接口：支持 4*MIPI CSI/sub LVDS 和 DVP 接口（BT.656/BT.1120），可连接多个摄像头。视频编解码方面，支持 4K H.264/H.265 30fps 的视频编码和解码，还可实现 3840 x 2160\@30 fps+720p\@30 fps 的编码以及 3840 x 2160\@30 encoding + 3840 x 2160\@30 fps 的解码。
- 其他接口：新增 USB 3.0 接口，提供更高的数据传输速率；内置百兆以太网 PHY，简化网络接口设计；集成音频编解码器（Audio Codec），支持高质量音频处理。

目标应用
----------

- 智能安防：支持人脸识别、车牌识别等目标检测功能，可应用于门禁系统、行为分析设备等。其集成的 AI-ISP 引擎结合 AI Remosaic 技术，能实现日夜双模自适应画质优化，同时 AOV 3.0 技术支持低功耗音频事件唤醒功能，可实时检测异常音频，待机功耗低至约 1mW，能实现 7×24 小时音视频联合监测，适用于智慧城市级的安防设备部署。
- 工业视觉：可用于精密零件质检、生产线缺陷检测等场景，结合 AI 算法能够实现微米级精度。此外，RV1126B 支持双目 / 四目全景动态拼接技术和 6-DOF 硬件级数字防抖，可消除画面撕裂，实现超广角视野，还能在低照度环境下保持清晰成像，适用于机器人导航及 PLC 控制辅助系统等工业场景。
- 智能车载：可用于行车记录仪、车载 DVR 等多路视频录制设备，支持 H.264/H.265 编码及 4K 视频解码，能适应车载环境的宽温运行要求（-40℃~+85℃）。同时，它还支持 8 路 1080P 视频同步处理，可应用于 ADAS 与 DMS 系统，提升行车安全。
- 服务机器人：凭借其强大的 CPU 和 NPU 性能，以及多模态处理能力，RV1126B 可用于服务机器人的多模态环境感知与路径规划，适用于仓储物流与医疗协作等场景，能够准确识别复杂场景中的目标对象，实现跨模态信息整合，为机器人的智能决策提供支持。
- 边缘计算：适用于智慧零售（如客流统计）、智慧农业（如病虫害识别）等边缘计算场景，提供硬件级安全与低功耗支持，其 3Tops 的算力和高效的编码解码能力，能够在边缘端快速处理数据，实现 7×24 小时全天候监测。

主要特点
---------

- 强大的算力引擎：搭载四核 Cortex-A53 CPU 架构，主频可达 1.5GHz，性能达同档位芯片 2 倍以上。内置自研 NPU，算力高达 3Tops，支持 INT8/INT16/FP16 等数据类型，以及权重稀疏化、W4A16/W8A16 混合精度量化及 Transformer 优化技术，可流畅运行 2B 以内参数规模的大语言模型与多模态模型。
- 优秀的图像处理能力：集成专用 AI-ISP 硬件，运行时无需占用 NPU 资源，结合 AI Remosaic 技术可实现 “日夜双模自适应”，白天呈现超高清画质，夜晚在超低照度下仍保持清晰成像。支持 800 万像素 45FPS 超高清编码，通过动态码率优化技术，较传统 CBR 模式节省 50% 码流。此外，还具备硬件级 6-DOF 数字防抖，精准识别并消除高频抖动，让运动图像更加流畅，同时支持双目 / 四目全景动态拼接技术，提供超广角视野。
- 低功耗与音频监测：新增的 AOV3.0 技术融入低功耗音频事件唤醒功能，可实时检测狗吠、玻璃破碎、枪声等异常声源，设备待机功耗低至 1mW 左右，支持 7×24 小时全天候音视频监测。
- 硬件级安全保障：内置国密级安全方案，支持 SM2/SM3/SM4 加密算法，集成 TrustZone 安全隔离技术与 keyladder 密钥管理系统，从数据采集到存储，以及 AI 算法模型的保护，进一步满足对安全性要求极高的应用场景。
- 丰富的接口与功能：DDR 带宽从 2166MT/S 跃升至 3200MT/S，数据传输速率显著加快。新增 USB 3.0 接口，提供更高的数据传输速率；内置百兆以太网 PHY，简化网络接口设计；集成音频编解码器（Audio Codec），支持高质量音频处理。此外，Sensor 接入数量增加至 4 个，支持多摄像头同步处理，拼接性能和畸变矫正性能也都有显著提升。
