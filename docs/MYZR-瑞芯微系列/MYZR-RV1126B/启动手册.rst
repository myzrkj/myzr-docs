启动手册
=========

开发板连接
------------

1. 检查电源开关

|  将开发板的开关电源 “POW_KEY” 拨到 “OFF” 一侧，以确保开发板电源开关处于断开状态。

2. 连接串口线

|  把Type-C线的一端连接到开发板的“Debug”口，另一端连接到电脑的串口。
|  参考 :doc:`《Xshell 参考手册》 </docs/COMMON/Xshell.RM.参考手册>` 新建串口会话并打开会话。

3. 连接下载线

|  把 Type-C 线的一端连接 U5，另一端连接到电脑的后置 USB 口。

4. 连接电源线

|  把12V-2A电源适配器的一端连接到开发板的“J1”，另一端插入到市电（220V的交流电）插座。

启动开发板
------------

|  将开发板的开关电源 “POW_KEY” 拨到 “ON” 一侧，以使开发板电源开关打开。启动系统完成后，开发板自动登入。
