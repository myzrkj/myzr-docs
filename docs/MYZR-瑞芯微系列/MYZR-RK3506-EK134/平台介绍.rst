平台介绍
=========

产品简介
---------

- 芯片架构：采用三核 Cortex - A7（最高 1.5GHz）+ 单核 Cortex - M0 的多核异构设计，兼具高性能与实时性，可满足不同任务需求。
- 制程工艺：采用 22nm 先进制程，满负载运行（CPU 超频 1.6GHz，DDR800MHz）条件下，SoC 功耗不足 650mW，常温下温升小于 17℃，低功耗特性显著，能为手持设备、边缘节点等提供长效续航。
- 工业级特性：支持 - 40~85℃宽温运行，通过电磁兼容、高温高湿老化等严苛测试，具备工业级可靠性，能适应复杂恶劣的工业环境。
- 接口丰富：
  - 网络接口：集成双百兆以太网口，支持 IEEE1588 协议，适用于工业网络通信。
  - 存储接口：支持多种存储设备，如 SPI Flash、eMMC 等。
  - 音频接口：5×SAI、1×ADC、2×DSM 等，支持多种音频功能。
  - 其他接口：2×USB2.0 OTG、6×UART、2×CAN FD、3×SPI、3×I2C 等，满足不同设备的连接需求。
- 低延时响应：支持 AMP 多核异构架构，采用标准 RPMSG 核间通信机制，系统具备微秒级中断响应延迟（<5us）。在采用 stress - ng 加负载测试条件下，系统调度实时性延时可达 60+us；基于 EtherCAT IgH 和 CODESYS 协议的系统，控制周期为 1 毫秒时抖动延时 90us 左右，可支持 8 轴总线控制。
- 显示与图形处理：内置 2D 硬件引擎和显示输出引擎，支持 MIPI - DSI、RGB 等显示接口，最大输出分辨率为 1280×1280@60fps，可满足图像显示和简单图形处理需求。
- 系统支持：原生支持 Linux Kernel 6.1，兼容 Buildroot、Debian、Ubuntu 等发行版，首次在瑞芯微平台实现 RTOS SMP 模式，支持 AMP 多核异构系统灵活调度。
- 启动速度：SDK 原生支持 LVGL 轻量级 UI 框架，结合芯片内部 2D 硬件加速，使 LVGL 运行更流畅。全链路启动优化后，不到 2.5s 即可极速开机。

目标应用
---------

- 智能家电：该处理器的超低功耗特性可满足智能家电长期运行的需求，而集成语音算法则能提升语音交互体验，例如智能冰箱、空调、洗衣机等家电的显控模块，可实现语音控制、状态显示、智能联网等功能，为用户提供更便捷、智能的使用体验。
- 工业控制：在工业控制领域，RK3506 可用于工业网关、PLC（可编程逻辑控制器）、HMI（人机界面）等设备。它支持双百兆以太网和多种工业协议，能助力工业设备实现互联互通；其多核异构架构和低延时响应特性，可满足 PLC 控制、EtherCAT 等实时任务需求，精准控制伺服电机等设备，实现高效、稳定的工业自动化控制。
- 手持终端：对于手持 POS 设备、手持工业终端等，RK3506 仅 200mW 的运行功耗提供了出色的便携性，较长的续航时间可满足移动支付、现场数据采集、物流配送等场景的需求。同时，其全流程安全加固方案也能保障数据的安全性和交易的可靠性。
- 楼宇对讲：可应用于楼宇对讲系统的室内机和门口机，提供高效的图形渲染能力和流畅的 UI 界面，支持视频通话、门禁控制、访客管理等功能，为楼宇的安全管理和居民的便捷生活提供支持。
- 视频和音频播放器：支持 720P 视频软解和集成音频算法，适用于一些对音视频播放有一定要求的小型设备，如便携式媒体播放器、数字标牌等，能够提供清晰的视频画面和优质的音频效果。


主要特点
---------

- 多核异构架构：采用三核 Cortex - A7（最高 1.5GHz）+ 单核 Cortex - M0 的多核异构设计，兼具高性能与实时性。其中，A7 核心处理复杂任务，M0 核心处理对实时性要求高的任务，如传感器数据采集、实时控制等。
- 工业级可靠性：支持 - 40~85℃宽温运行，通过电磁兼容、高温高湿老化等严苛测试，能适应复杂工业环境。
- 超低延时响应：AMP 多核异构设计实现 A 核微秒级、M0 核百纳秒级响应，满足 PLC 控制、EtherCAT 等实时任务需求。在采用 stress - ng 加负载测试条件下，系统调度实时性延时可达 60+us，基于 EtherCAT IgH 和 CODESYS 协议的系统，控制周期为 1 毫秒时抖动延时 90us 左右。
- 低功耗：采用 22nm 先进制程，满负载功耗不足 0.7W，常温温升小于 17℃，为手持设备、边缘节点提供长效续航。
- 星闪技术支持：支持星闪（SparkLink）技术，融合蓝牙低功耗与 Wi - Fi 高吞吐量优势，为工业物联网提供低时延、高可靠、强抗干扰的无线连接方案。
- 全链路极速启动：通过 LVGL 轻量级 UI 框架优化与全链路启动加速，可实现 3 秒内极速开机，提升工业设备响应效率。
- 多系统支持与开发友好性：原生支持 Linux Kernel 6.1，兼容 Buildroot、Debian、Ubuntu 等发行版，并首次在瑞芯微平台实现 RTOS SMP 模式，支持 AMP 多核异构系统灵活调度。
- 丰富的接口：集成双百兆网、2 路 CAN FD、6 路 UART（部分接口复用）、USB 2.0 OTG 等工业级接口，并内置 2D 硬件加速引擎，支持 1280×1280 分辨率显示输出，满足 HMI 人机交互与多设备协同需求。
