启动手册
=========

准备工具软件
-------------


* **下载并解压文件**

  * 打开网盘到 `1.通用资料` ，下载 `1.3-工具` 目录。
  * 解压 `1.3-工具/TeraTerm.v4.108.zip` ，在解压的目录里有 `ttermpro.exe`，这是我们后面需要使用的串口工具。


开发板连接
-----------

* **连接电源**

  * 把开发板的电源开关（丝印 **SW3**）拨到 **OFF** 位置，以确保开发板电源开关处于断开状态。
  * 将电源连接到开发板的电源插头（丝印 **P3**）。
    **提示**：开发板支持 **12 ~ 24V** 供电。


* **连接调试线**

  * 使用 `USB Type-C` 数据线连接开发板的 Type-C 座子（丝印 `CON2`）和电脑，打开电脑的设备管理器，可以看到 `端口（COM 和 LPT）` 下面多出一个 `USB-SERIAL CH340 (COMx)`，记住 `COMx` 这个串口号，后面需要使用。

    * **提示**：这里不需要给开发板上电，电脑上也会出现  `USB-SERIAL CH340 (COMx)` 设备。
    * 如果连接 Type-C 线后 `USB-SERIAL CH340 (COMx)` 上有一个三角形的感叹号，则需要电脑更新 CH340 的驱动（驱动位置`1.3-工具/MYZR-RZV2H-USB驱动.zip`）。
    * 如果连接 Type-C 线后没有多出一个 `USB-SERIAL CH340 (COMx)` 设备，则换一条 Type-C 线，以及换一台电脑连接。

* **连接网线**

   *  把网线的一端连接到开发板的第一个网口（丝印 **ETH0**），另一端连接到电脑的网口。


* **连接 HDMI 显示屏**

   * 将HDMI显示屏连接到开发板HDMI接口（丝印 ***HDMI***），并为 HDMI 显示屏上电。

    **提示**： 建议使用 1080P 分辨率的 HDMI 显示屏，以及使用原生 HDMI 接口的显示屏，而不是转接为 HDMI 接口的。


启动开发板
------------

* **配置串口**

  * 运行解压 `1.3-工具/TeraTerm.v4.108.zip` 得到的 `ttermpro.exe` 。

  * 新建连接时选择前面接上 Type-C 线时出来的 COM 口。

   .. figure:: /image/MYZR-瑞萨系列/MYZR-RZV2H-EK320/TeraTerm.Serial.New.png
      :alt: TeraTerm.Serial.New.png

  * 点击 Tera Term 菜单栏的 `Setup -> Serial port...` ，选择好参数。

   .. figure:: /image/MYZR-瑞萨系列/MYZR-RZV2H-EK320/TeraTerm.Serial.Setup.png
      :alt: TeraTerm.Serial.Setup.png

  * 点 Tera Term 软件菜单栏的 `Setup -> Save setup` 保存配置，文件名和路径默认即可。这样下次使用时会自动载入我们刚才的配置。

* **拨码到启动模式**

  * 把模式拨码（丝印 `SW2`）的 **1** 拨到 **ON**，**2** 拨到 **OFF**。


* **接通电源**

  * 把电源开关拨到 **ON** ，使开发板的电源接通，在 Tera Term 软件上可以看到开发板输出的信息。


启动信息
----------


* **说明**

  * 开发板连接并配置好串口后，通电时在串口终端软件上可以看到开发板输出的启动信息，包括 Boot 输出信息、内核输出信息、文件系统加载信息。

* **Boot 信息**

  * 开发板最先启动的是 Boot，Boot 输出的信息类似如下：

  .. code-block:: shell

     NOTICE:  BL2: v2.7(release):3ff5203
     NOTICE:  BL2: Built : 08:59:25, May 26 2025
     NOTICE:  BL2: Booting BL31
     NOTICE:  BL31: v2.7(release):3ff5203
     NOTICE:  BL31: Built : 08:59:25, May 26 2025


     U-Boot 2021.10 (May 27 2025 - 07:07:53 +0000)

     CPU:   Renesas Electronics CPU rev 1.0
     Model: MYZR RZV2H LGA320 Evaluation Kit - 4GB Memory
     DRAM:  3.9 GiB
     MMC:   mmc@15c00000: 0, mmc@15c10000: 1
     Loading Environment from MMC... *** Warning - bad CRC, using default environment

     In:    serial@11c01400
     Out:   serial@11c01400
     Err:   serial@11c01400
     Net:   eth0: ethernet@15c30000
     Hit any key to stop autoboot:    


  * 其中行首是 `NOTICE` 的是 `trusted-firmware-a` 信息，主要有：

    **版本**：`v2.7(release):3ff5203`

    **编译时间：** `Built : 08:59:25, May 26 2025`

  * `U-Boot 2021.10` 开始到最后一行是 U-Boot 信息，主要有：

    **版本和编译时间**：`U-Boot 2021.10 (May 27 2025 - 07:07:53 +0000)`

    **开发板信息**：`MYZR RZV2H LGA320 Evaluation Kit - 4GB Memory`

* **内核信息**

  * 从 `Starting kernel` 开始是内核信息，主要如下：

开发板登录
------------

* 在系统输出 `myzr-rzv2h-ek320 login:` 时，可以登录：

  **用户名**：root

  **密码**：无

  **提示**：登录后可以通过 **passwd** 命令来设置和修改密码。

.. code-block:: shell

   myzr-rzv2h-ek320 login: root
   root@myzr-rzv2h-ek320:~#
