平台介绍
=========

产品简介
----------

- RZV2H是一款专为高性能边缘AI视觉设计的处理器，通过异构多核与专用加速器平衡通用计算、实时控制和AI推理需求，适合工业、医疗、车载等严苛环境的应用开发。有强大的计算能力、低功耗，适用于工业自动化、机器人、智能摄像头等场景。 

目标应用
----------

- 工业机器视觉： 缺陷检测、条形码识别、自动化分拣。 
- 智能摄像头： 实时人脸识别、行为分析、安防监控。 
- 机器人： SLAM（同步定位与建图）、物体抓取导航。 
- 医疗设备： 内窥镜图像处理、医疗影像分析。
- 汽车ADAS：辅助驾驶中的实时图像处理（需结合车规级芯片）。

主要特点
---------

- **高性能异构多核架构**：

- 双核Arm Cortex-A76（1.8 GHz）：处理通用操作系统（如Linux）和复杂应用。
- 双核Arm Cortex-R8（1.0 GHz）：负责实时控制任务。
- 双核瑞萨自研DSP（1.0 GHz）：优化用于视觉处理和AI推理。
- IMR（智能可重构处理器）：硬件加速器，支持实时图像处理（如ISP、降噪、HDR）。

- **AI加速能力**：

- 集成 DRP-AI（动态可重构处理器） 和 AI-MAC 单元，支持主流AI框架（TensorFlow、PyTorch等）。
- 典型性能：10 TOPS（INT8），可高效运行目标检测、分类等AI模型。

- **图像处理单元**：

- 支持多摄像头输入（最高4K分辨率）。
- 硬件加速H.264/H.265编解码，ISP（图像信号处理器）支持降噪、畸变校正等。

- **丰富的外设接口**：

- 视频输入：MIPI CSI-2、并行接口。
- 显示输出：HDMI、MIPI DSI。
- 网络：千兆以太网、TSN（时间敏感网络）。
- 其他：USB 3.0、PCIe、CAN FD、SPI、I2C等。

- **低功耗设计**：

- 采用16nm FinFET工艺，平衡性能与功耗，适合边缘设备。
