平台介绍
=========

产品简介
----------

   * 全志H618是一款面向智能电视盒子、智能显示终端、教育平板及边缘计算设备的高性价比多媒体处理器。它基于四核Cortex-A53架构，集成Mail-G31 MP2 GPU，支持8K@24fps的H.265视频解码和4K@25fps的H.264视频编码，具有丰富的影音接口，可应用于OTT、智慧屏幕等产品形态。主要面向智能终端、多媒体处理、物联网（IoT）及消费电子等领域。 

目标应用
----------

   * 智能电视与机顶盒：4K HDR视频播放、流媒体服务（如Netflix、YouTube）硬件解码。 支持Android TV系统，集成语音助手、智能推荐功能。
   * 平板电脑与教育设备： 多任务处理、触控交互、电子书阅读及在线教育应。 
   * 工业控制与IoT网关： 通过Linux系统实现设备控制、数据采集及边缘计算。支持RS485/232、CAN总线等工业接口扩展。 
   * 智能家居中控： 语音控制（集成麦克风陈列）、安防监控（摄像头输入+AI人脸识别）。
   * 商用显示与广告机： 多屏互动、远程内容管理、高辨率广告播放。

主要特点
----------

   * 4核Arm Cortex-A53
   * 支持最高8K@24fps H.265解码及4K@25fps H.264编码
   * 支持最高4K@60fps HDMI，以及TV CVBS OUT显示输出
   * 支持HDR10, HDR10+, HLG, HDR vivd
