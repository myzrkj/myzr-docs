标准GPIO测试
--------------

|  【测试说明】：控制GPIO的输出电平
|  【系统接口】：/sys/class/gpio/

**测试操作**

|  输入命令控制 IO 输出高电平：
|  =====> 输入指令

.. code-block:: shell

   export OUT_IO_OUT_NUM=67
   echo ${OUT_IO_OUT_NUM} > /sys/class/gpio/export
   echo "out" > /sys/class/gpio/gpio${OUT_IO_OUT_NUM}/direction
   echo 1 > /sys/class/gpio/gpio${OUT_IO_OUT_NUM}/value

|  这时用万用表测试 引脚16，电压应当是 3.3V。
 
|  控制 IO 输出低电平：

.. code-block:: shell

   echo 0 > /sys/class/gpio/gpio${OUT_IO_OUT_NUM}/value

|  这时用万用表测试 引脚16，电压应当是 0V。
 
|  输入测试：
|  说明：通过系统的接口配置并读取GPIO的输入电平。用杜邦线或跳线帽连接 16 和22脚。
|  输入命令导出 IO 操作接口并配置为输入：

.. code-block:: shell

   export OUT_IO_IN_NUM=71
   echo ${OUT_IO_IN_NUM} > /sys/class/gpio/export
   echo "in" > /sys/class/gpio/gpio${OUT_IO_IN_NUM}/direction

|  输入命令控制 16 输出高电平并读取 22的输入电平：

.. code-block:: shell

   # 控制16 IO 输出高电平
   echo 1 > /sys/class/gpio/gpio${OUT_IO_OUT_NUM}/value
   # 读取 IO 的输入电平
   cat /sys/class/gpio/gpio${OUT_IO_IN_NUM}/value

|  这时命令行界面终端应当输出字符“1”（表示高电平）。
 
|  输入命令控制 16输出低电平并读取 22的输入电平：

.. code-block:: shell

   # 注释：控制 16输出低电平
   echo 0 > /sys/class/gpio/gpio${OUT_IO_OUT_NUM}/value
   # 注释：读取 IO 的输入电平
   cat /sys/class/gpio/gpio${OUT_IO_IN_NUM}/value

|  这时命令行界面终端应当输出字符“0”（表示低电平）。
|  测试结果：在测试操作中，读取到的电平符合正确预期，即功能正常。

PWM测试
---------

|  【测试说明】：板卡上集成了一个具有 pwm 功能的 GPIO，该 PWM 引脚与板载的 FAN 接口 共用。
|  【接口标识】：引脚12
|  【系统设备】： /sys/class/pwm
 
**测试操作**

|  需提前执行echo 1 > /sys/class/pwm/pwmchip0/export导出 PWM1 通道（假设使用 pwmchip0 的 pwm1）。

.. code-block:: shell

   echo 1 > /sys/class/pwm/pwmchip0/export

|  通过echo命令设置周期、占空比并启用 PWM：

.. code-block:: shell

   echo 1000000 > /sys/class/pwm/pwmchip0/pwm1/period
   echo 500000 > /sys/class/pwm/pwmchip0/pwm1/duty_cycle
   echo 1 > /sys/class/pwm/pwmchip0/pwm1/enable

|  =====> 输入指令

.. code-block:: shell

   ./pwm

|  =====> 输出信息

.. code-block:: shell

   root@TinaLinux:/mnt/exUDISK/my-h618-test# ./pwm
   PWM 周期: 1000000 ns
   占空比: 50.0 %
   使能状态: 开启

**测试结果：** 能正常输出相应信息表示测试通过，若 PWM 通道未导出或路径错误，文件不存在，程序会读取到空字符串，atol(buf)返回 0，输出：

|  PWM 周期: 0 ns
|  占空比: 0.0 %
|  使能状态: 关闭
