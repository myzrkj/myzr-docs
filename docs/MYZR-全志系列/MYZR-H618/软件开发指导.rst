软件开发指导

源码编译
---------

配置环境
~~~~~~~~~~

|   进入aw-image-build根目录下输入如下指令配置环境

.. code-block:: shell

    cd aw-image-build
    ./build.sh

|   完成后会进入aw-image-build功能的选择页面，各选择如下

.. code-block:: shell

    Select to build all | image | rootfs | kernel | u-boot: update source repository
    Please choose a Board.: lubancat-a1 Allwinner H618
    Select source mirror: Github Open source code repository

整体编译
~~~~~~~~~

|   进入aw-image-build根目录下输入如下指令进入交互式构建界面

.. code-block:: shell

    cd aw-image-build
    ./build.sh

- 在"Select to build all | image | rootfs | kernel | u-boot"选择"Build all step"，接下来的其他配置根据需求选择即可

局部编译
~~~~~~~~~

|   进入aw-image-build根目录下输入如下指令进入交互式构建界面

.. code-block:: shell

    cd aw-image-build
    ./build.sh

单独编译Kernel
^^^^^^^^^^^^^^^

- 在"Select to build all | image | rootfs | kernel | u-boot"选择"step1.Build Kernel"，接下来的其他配置根据需求选择即可

单独编译U-boot
^^^^^^^^^^^^^^^

- 在"Select to build all | image | rootfs | kernel | u-boot"选择"step2.Build U-boot"，接下来的其他配置根据需求选择即可

单独编译rootfs及本地自定义的 deb 软件包
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

- 在"Select to build all | image | rootfs | kernel | u-boot"选择"step3.Build base-rootfs and deb packages"，接下来的其他配置根据需求选择即可

打包镜像
~~~~~~~~~~

1. 进入aw-image-build根目录下输入如下指令进入交互式构建界面

.. code-block:: shell

    cd aw-image-build
    ./build.sh

2. 在"Select to build all | image | rootfs | kernel | u-boot"选择"step4.Pack image"，接下来的其他配置根据需求选择即可
