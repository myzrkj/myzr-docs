平台介绍
=========

产品简介
---------

| 全志T113芯片是一款集成双核Cortex-A7 CPU、64位玄铁C906 RISC-V CPU和DSP的处理器，主频为1.2GHz。支持全格式解码和多种格式编码，具备丰富的多媒体功能，以及广泛的连接接口，如USB、SDIO、UART、SPI、CAN、以太网等。该芯片适用于工业、电力、交通等关键领域。

目标应用
---------

- 工业HMI：小型触摸屏控制面板（如PLC交互界面）、HMI人机界面。 
- 智能家居中控： 语音识别网关、低功耗显示终端、智能中控屏、语音助手（需外接DSP/AI模块）。 
- 物联网边缘设备： 数据采集网关（CAN/UART转Wi-Fi/以太网）、低功耗传感器网关。 
- 消费电子： 教育平板、便携式医疗设备。
- 车载设备：车载信息娱乐系统（IVI）、倒车影像。


主要特点
---------

- 高性价比： 相比同类产品，价格更低、适合成本敏感型应用。 
- 混合架构： Cortex-A7 + RISC-V兼顾通用计算与实时性需求。 
- 工业级可靠性： 支持-40°C至+85°C宽温运行。
- 宽温工业级支持。
- 极低待机功耗。
