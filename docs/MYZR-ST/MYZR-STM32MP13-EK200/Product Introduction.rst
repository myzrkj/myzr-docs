| **Product Introduction:**
| 　• **MYZR STM32MP13 Development Board** (MYZR-STM32MP13-EK200) enables customers to conveniently evaluate the MYZR-STM32MP13-CB200 core board, providing a foundation and reference for customers to design their own hardware.
| 　• **MYZR STM32MP13 Core Board** (MYZR-STM32MP13-CB200) is an STM32 Arm Cortex-A7 class microprocessor with an operating frequency of 650MHz, up to a maximum of 1GHz.

| **Target Applications:**
| 　• **Smart Home:** AI local servers, alarm and security systems, intelligent robots, network nodes, control, and other home automation applications.
| 　• **Smart Metering:** Heat metering, smart plugs, gas metering, water metering, and electricity metering.
| 　• **Industrial and Factory Automation:** Industrial sensors, connectivity and PLCs; Industry 4.0; industrial robots.

| **Key Features:**
| 　• **Core:** Single-core Arm Cortex-A7, with a maximum main frequency of up to 1GHz; 32kB+32kB I/D L1 cache; 256kB L2 cache.
| 　• **Internal Memory:** 256KB system RAM; 384kB MCU system RAM; 64kB MCU reserved RAM.
| 　• **External Memory Support:** DDR 3, DDR3L, LPDDR 2, LPDDR 3; eMMC, SD card, Quad-SPI NOR.
| 　• **Others:** Multiple communication peripherals, multiple GPIO interfaces, and analog interfaces.
