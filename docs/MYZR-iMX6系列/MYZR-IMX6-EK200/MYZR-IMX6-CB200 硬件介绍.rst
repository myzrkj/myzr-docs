温度范围
~~~~~~~~~

- 商业级：

      0°C ~ 70°C

- 工业级：

      -40°C ~ 85°C

- 汽车级：

      -40°C ~ 125°C

**存储温度**

      -60°C ~ 125°C

| 接口规格     |            | 最大可配置接口数 | 描述                                                 |

|              | USB        | 2                | 1路USB2.0 1路OTG接口，最高速率480M                   |
+              +------------+------------------+------------------------------------------------------+
|              | UART       | 5                | 5路UART,每路高达4.0Mbps                              |
+              +------------+------------------+------------------------------------------------------+

+              +------------+------------------+------------------------------------------------------+
|              | I2C        | 3                | 3路I2C,最高支持400 kbps                              |
+              +------------+------------------+------------------------------------------------------+
|              | SPI        | 2                | 2路eCSPI,每个高达52Mbps                              |
+              +------------+------------------+------------------------------------------------------+
|              | FlexCan    | 2                | 2路CAN2.0,最高速率1 Mb/sec                           |
+              +------------+------------------+------------------------------------------------------+
|              | PWM        | 4                | 4路16位计数器，4x16 FIFO                             |
+--------------+------------+------------------+------------------------------------------------------+
| 外部存储接口 | SPI-NOR    | 1                | 1路外部SPI接口存储设备                               |
+              +------------+------------------+------------------------------------------------------+

供电电源
~~~~~~~~~~

|  5V输入

默认显示选择
~~~~~~~~~~~~~

**LVDS0**

|  LVDS0 7寸 TFT液晶显示（24bit LVDS接口）
|  分辨率1024X600@60Hz
|  白色背光
|  电容触摸

**LVDS1**

|  LVDS1 7寸 TFT液晶显示（24bit LVDS接口）
|  分辨率1024X600@60Hz
|  白色背光
|  电容触摸

**RGB**

|  7寸 TFT液晶显示（24bit RGB接口）
|  分辨率800X480@60Hz
|  白色背光
|  电容触摸

**HDMI**

|  HDMI输出 （24bit HDMI接口）
|  1920X1080@60Hz 兼容16/18/24bpp
