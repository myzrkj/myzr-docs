Specifications
----------------

Hardware Configuration
~~~~~~~~~~~~~~~~~~~~~~~~

+---------+------------------------+
|   CPU   |        LS1012A         |
+=========+========================+
| Memory  | 512MB DDR3L            |
+---------+------------------------+
| Storage | 64MB SPINOR + 4GB eMMC |
+---------+------------------------+

Power Supply
~~~~~~~~~~~~~~

|  3.3V Input

CPU Power Consumption
~~~~~~~~~~~~~~~~~~~~~~~~

|  Status: No Load
|  Operating Voltage: 3.3V
|  Operating Current: 440mA

Temperature Range
~~~~~~~~~~~~~~~~~~~

**Operating Temperature**

 | 0°C ~ 70°C (Commercial Grade)
 | -40°C ~ 85°C (Industrial Grade)

**Storage Temperature**

 | -60°C ~ 125°C

Supported Operating Systems
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- Linux:

 | linux-4.1.35

- rootfs:

 | ramdisk and openwrt
