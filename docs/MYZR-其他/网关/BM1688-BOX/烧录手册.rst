烧录手册
========

每次编译好之后会在/project/sophon/1688_v2.0_source/install/soc_edge_wevb_emmc/package_edge生成sdcard.tgz的SD卡镜像，把这个压缩包的文件解压到SD卡里面（解压出来有75个文件），然后把SD卡放到板子的卡槽（U11），然后接上串口（U6）上电就可以看到烧录日记提示在升级过程，升级完成会提示reboot，直接断电重启就可以。
