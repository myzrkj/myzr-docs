平台介绍
========

产品简介
--------

MYZR‑BM1688‑BOX 是基于算能 SOPHGO BM1688 异构 AI 芯片打造的工业边缘 AI 计算整机，集成双千兆以太网、隔离 RS232/RS485、双路 CAN‑FD、MIPI 摄像头接口、HDMI 显示、M.2 无线与固态扩展、音频等外设，支持多路视频编解码、本地 AI 推理、工业协议数据处理，适用于工业机器视觉、智慧安防、离线大模型、物联网边缘网关、零售智能分析等场景，工作温度‑20℃~+70℃，对外接口具备 ESD、浪涌防护，满足工业严苛环境使用。

目标应用
--------

1.工业机器视觉检测
~~~~~~~~~~~~~~~~~~

产线工件缺陷识别、尺寸测量、物料分拣计数、条码二维码读取；搭配 CAN/RS485 总线直连 PLC、变频器，实现视觉检测与设备联动，支持产线本地数据存储，无需云端上传。

2.智慧园区 & 安防视频结构化
~~~~~~~~~~~~~~~~~~~~~~~~~~~

多路摄像头同时做人脸识别、车牌识别、行人 / 电动车 / 遗留物检测、越界闯入告警；支持 16 路 1080P 视频同步解码分析，本地保存录像，保障园区数据隐私。

3.零售门店智能分析
~~~~~~~~~~~~~~~~~~

门店客流统计、货架商品识别、顾客停留行为分析；搭载 WiFi/4G 无线模块，可远程同步统计数据，离线状态也能完成本地算法推理。

4.离线私有化大模型终端
~~~~~~~~~~~~~~~~~~~~~~

本地部署轻量级大语言模型、语音交互模型，企业知识库离线问答、设备语音控制；所有数据仅在盒子内部处理，不上云，满足数据保密需求。

5.智能交通后装设备
~~~~~~~~~~~~~~~~~~

车载多路行车画面采集、道路目标检测、违章识别；宽温无风扇结构适配车载高低温环境，支持本地视频存储回放。

6.物联网工业边缘网关
~~~~~~~~~~~~~~~~~~~~

采集温湿度、红外、称重等各类传感器数据，本地预处理后分流传输；双千兆网口实现内外网隔离，兼顾设备采集与后台上传。

7.AI 教学与算法验证平台
~~~~~~~~~~~~~~~~~~~~~~~

高校、研发实验室深度学习调试设备，支持多路摄像头并发、多模型并行推理，配套完整 SDK，用于 CV 视觉、NLP 算法开发测试。

8.仓储物流智能识别
~~~~~~~~~~~~~~~~~~

货物盘点、快递面单 OCR 识别、堆垛异常检测，适配仓库密闭、高低温工作环境。

主要特点
--------

*  采用 A53+RISC-V+TPU 三核异构架构，16TOPS 算力，支持多路 AI 同步推理；

*  内置 4K ISP 与多路视频编解码，可同时接入多路 MIPI 摄像头；

*  底板集成双千兆网、CAN/485、M.2 无线 / 固态等全工业外设接口；

*  铝合金无风扇整机，-20℃~+70℃宽温，7×24 小时稳定运行；

*  内存、eMMC 容量可灵活选配，支持 TF/NVMe 多级本地存储；

*  配套完整 Linux SDK 与编译环境，模型移植、固件开发便捷；

*  支持 TF/eMMC/USB 三种启动模式，调试烧录一体化 Type-C 接口；

*  整机低功耗，体积小巧，支持机柜、壁挂两种安装方式。
