RS232-1/RS485测试
-----------------

【测试说明】：采用短接TX RX方式进行测试231-1,采用485转usb模块测试485

【接口标识】: CON2

【系统设备】：/dev/ttyS7

【测试操作】：

找到旁边的U17拨码开关

当1拨码ON，2拨码OFF时，SLE1高电平，切换到RS23-1

当1拨码OFF，2拨码ON时，SLE1低电平，切换到RS485

1.切换到RS23-1，用两头尖的杜邦线短接上排的第二第三这两个小孔，输入指令，收到输出信息

.. code-block:: text

   cvi_pinmux -w PAD_VIVO0_D15/UART7_TX
   cvi_pinmux -w PAD_VIVO0_D16/UART7_RX
   ./serial_test.out /dev/ttyS7 123

2.切换到RS485，使用485转usb模块，485转usb模块的A接上排的第二个小孔，B接接上排的第三个小孔，开启485终端，在系统终端输入下面指令，485终端能接到信息，485终端输入123（不显示输入状态），系统可以接收到信息

.. code-block:: text

   cvi_pinmux -w PAD_VIVO0_D15/UART7_TX
   cvi_pinmux -w PAD_VIVO0_D16/UART7_RX
   ./serial_test.out /dev/ttyS7 123

CAN测试
-------

【测试说明】：采集摄像头画面来验证连接正常

【接口标识】: U32

【系统设备】：

【测试操作】：

启动两个板子，板1U32左上角1接接板2U32左上角1，板1U32左上角2接接板2U32左上角2

1.板1接收，板2发送

板1配置如下

.. code-block:: shell

   busybox devmem 0x2810450c 32 0x3838
   busybox devmem 0x27011004 32 0x800
   busybox devmem 0x27011000 32 0x0
   
   ip link set can0 down
   ip link set can0 type can bitrate 500000
   ip link set can0 up
   板1进入接收状态
   candump can0

板2配置如下

.. code-block:: shell

   busybox devmem 0x2810450c 32 0x3838
   busybox devmem 0x27011004 32 0x800
   busybox devmem 0x27011000 32 0x0
   
   ip link set can0 down
   ip link set can0 type can bitrate 500000
   ip link set can0 up
   板2进入发送状态
   cansend can0 -e -i 0x1F334455 0x11 0x22 0x33 0x44 0x55 0x66 0x77 0x88

此时板1的终端会收到板2发送的数据

.. code-block:: text

   root@sophon:~# candump can0
   interface = can0, family = 29, type = 3, proto = 1
   
   <0x1f334455> [8] 11 22 33 44 55 66 77 88

2.板1发送板2接收

板2配置接收

.. code-block:: text

   root@sophon:~# candump can0

板1配置发送

.. code-block:: text

   cansend can0 -e -i 0x1F334455 0x11 0x22 0x33 0x44 0x55 0x66 0x77 0x88

此时板2的终端会收到板1发送的数据

.. code-block:: text

   root@sophon:~# cansend can0 -e -i 0x1F334455 0x11 0x22 0x33 0x44 0x55 0x66 0x77 0x88
   interface = can0, family = 29, type = 3, proto = 1
   root@sophon:~# candump can0
   interface = can0, family = 29, type = 3, proto = 1

RTC测试
-------

【测试说明】：读取并设置时间，断电重启后检查时间是否正确

【接口标识】：U13

【系统设备】：/dev/rtc0

【测试操作】：

1.在U13安装上纽扣电池，输入以下指令

.. code-block:: text

   timedatectl set-ntp false
   date -s "2025-5-14 10:30:00"
   date
   hwclock -w
   hwclock -w
   hwclock -r
   hwclock -r

2.板子断电一会，然后上电启动ck时间是否继续走

.. code-block:: text

   hwclock -r
   date
