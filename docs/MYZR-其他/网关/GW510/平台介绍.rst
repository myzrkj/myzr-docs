平台介绍
=====================

产品简介
-----------

MYZR-SSD2351-GW510（GW510-4G）是基于 SigmaStar SSD2351 四核工业芯片打造的工业多模通信网关，集成隔离 RS485/RS232、百兆以太网、DI/DO、继电器、4G/WiFi/ 蓝牙 / LoRa 多通信链路，支持串口转 MQTT 等工业协议透传，适用于工业自动化、智慧能源、老旧设备云改造、远程运维等场景，工作温度 -20℃~75℃，全接口带 4KV 防雷，满足工业严苛环境。

目标应用
-----------

- 工业自动化：工厂车间传感器、PLC、仪表数据采集，设备远程启停、状态监控；
- 智慧能源：电力电表、光伏设备、水务仪表 RS485 数据上云，能耗监测与远程抄表；
- 远程运维：野外设备、工程机械、无人值守机房的数据回传与远程控制；
- 物联网组网：园区、楼宇多节点设备无线组网，串口设备统一接入物联网平台；
- 传统设备改造：老旧 RS485/RS232 工业设备快速联网升级，低成本实现智能化、云化改造。

主要特点
-----------

- 性能稳定：采用 Cortex-A35 四核处理器，主频 1.4GHz，支持 7×24 小时连续工作；板载 RTC 时钟与备份电池，断电仍可正常计时。
- 接口丰富：搭载多路隔离 RS485、RS232、百兆以太网、数字量 IO 及继电器接口，全系通信口具备 4KV 防雷保护，适配各类工业设备。
- 多模无线：集成 4G、双频 WiFi、蓝牙、LoRa，组网方式灵活，满足本地、远程、远距离等不同联网需求。
- 协议透传：支持 RS485/RS232 与 MQTT 双向透明传输，Web 页面可视化配置，快速实现串口设备上云与远程控制。
- 工业防护：-20℃~75℃宽温工作，支持 12V/24V 宽压供电，具备过压、过流、防反接、防静电等多重保护；铝制外壳，导轨式安装，适配工业现场。
- 运维便捷：支持多方式登录调试，状态指示灯直观显示运行状态，配套完整开发资料，支持二次开发与远程维护。
