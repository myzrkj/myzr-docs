

MYZR-IMX6-MB166 Hardware Introduction
=======================================

MYZR-R16-MB166 Introduction
----------------------------

Size
~~~~~

   |  120mm * 180mm

Power supply
~~~~~~~~~~~~~

   |  5V input

Temperature range
~~~~~~~~~~~~~~~~~~~

- **working temperature**
   | 0°C ~ 70°C

- **Storage temperature**
   | -40°C ~ 85°C

Operating system support
----------------------------

- **Linux**
   | Linux-3.4.39

- **Android**
   | Android 4.4（Use the Linux-3.4.39 kernel）
