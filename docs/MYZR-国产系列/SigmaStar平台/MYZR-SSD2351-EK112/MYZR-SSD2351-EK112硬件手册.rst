第一章 MY-SD2351-CB112核心板介绍
---------------------------------

1.1 核心板介绍
~~~~~~~~~~~~~~~~

CPU性能
^^^^^^^^^

1. 处理器核心
"""""""""""""""

- ARM Cortex-A35 四核
- 每个核心：32KB L1指令缓存 + 32KB L1数据缓存
- 256KB L2缓存
- 支持Neon和FPU（浮点运算单元）
- 每个核心独立的电源域
- 0.5 TOPS算力

2. 智能视频引擎 (IVE)
"""""""""""""""""""""""

- 纯硬件加速器
- 支持图像处理操作：Filter2D、Box filter、Gaussian filter、Bernsen、Dilate、Erode等
- 支持矩阵乘法

3. 智能处理单元 (IPU)
"""""""""""""""""""""""

- 纯硬件加速器
- 可编程4/8/16位处理
- 支持RGB/YUV数据格式的R/W DMA
- 支持多种视频分析功能：人脸检测/识别（FD/FR）、人体检测、运动检测/物体检测（MD/OD）、物体跟踪等
- 支持Transformer网络

4. 音频处理器
""""""""""""""

- 支持3通道ADC（单端或差分模式）
- 支持2通道DAC（单端模式）
- ADC和DAC的信噪比（SNR）超过95.2dB
- 支持数字和模拟增益调整
- 支持8通道DMIC（1时钟 + 4数据）
- 支持TDM模式（1250/1/2），最大输入8通道，输出2通道
- 支持SPDIF输入

5. 视频输出接口
""""""""""""""""

- 图像质量增强（gamma、锐度、亮度、3x3矩阵、颜色抖动、OSD、RGB交换）
- 显示通道支持MIPI/数字端口输出，数字端口包括TTL/18080
- 支持MIPI DSI TX，每通道2.5Gbps，RGB 16/18/24位，分辨率2560x1600@60fps
- TTL/并行RGB接口，16/18/24位，分辨率1280x800@60fps
- 支持8/16位18080接口
- 支持MIPI CSI

6. 高级色彩引擎
""""""""""""""""

- 亮度增益/偏移调整
- 黑白电平扩展（BLE/WLE）
- 峰值/低通滤波/色度校正/去噪

7. SPI NOR/NAND闪存接口
""""""""""""""""""""""""

- 兼容标准、双通道和四通道SPI闪存组件
- 最大时钟频率108MHz
- 支持断电保护

8. SD/eMMC接口
""""""""""""""""

- 兼容SD 2.0规范，支持1/4位数据总线模式
- 兼容SDIO 2.0规范，支持1/4位数据总线模式
- 支持eMMC 5.0，4/8位数据总线，最大时钟频率200MHz，HS400 DDR模式

9. USB接口
""""""""""""

- USB2.0端口0可配置为主机或设备
- USB2.0端口1可配置为主机或设备（主机模式支持EHC1规范）

10. DRAM内存
""""""""""""""

- 内置16位x1 DDR3/L，1Gb容量
- 数据速率高达2133Mbps（DDR3/L）

11. 网络连接
""""""""""""""

- 内置两个10/100M以太网MAC，支持RMII接口
- 256条目的哈希表
- 支持广播/组播风暴预防
- 支持全双工和半双工操作
- 支持IEEE 802.1Q VLAN标签检测
- 支持IPv4头部校验和以及TCP、UDP或ICMP校验和检查

12. 安全引擎
""""""""""""""

- 支持AES128/AES192/AES256/DES/3DES/RSA4096/SHA-1/SHA-256/SM2/SM3/SM4加密算法
- 支持安全启动
- 符合FIPS 140-1标准的随机数生成器
- 内置OTP（一次性可编程）存储器，用于存储安全数据和校准数据

13. 启动选项
"""""""""""""

- SPI NOR
- SPI NAND（带ECC）
- SD卡
- eMMC
- USB
- UART

14. 外设接口
""""""""""""""

- 专用GPIO用于系统控制
- 支持8路PWM输入和13路PWM输出（与GPIO共享）
- 支持QSPI接口
- 最多6个通用UART和4个带流控制的快速UART
- 最多12个通用定时器和1个看门狗定时器
- 两个SPI接口，可配置为主机或从机模式
- 两个仅主机模式的SPI接口
- 最多6个I2C主控制器
- 内置10位SAR ADC，1通道
- 支持7x7键盘
- 支持IrDA
- 支持POR（上电复位）
- 支持内部温度传感器
