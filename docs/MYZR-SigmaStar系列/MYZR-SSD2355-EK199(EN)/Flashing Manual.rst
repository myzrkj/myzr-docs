- Flashing Tool: UsbFactoryTool_1.0.0.19.tar.gz
- Image File: SstarUsbImage_202509190123.bin

Extract the Flashing Tool
----------------------------

- Right-click and extract to the current directory. This PC is 64-bit, please use the tool: USB_Factory_Tool_64_1.0.0.19.exe

Download
-----------

- Connect the power supply and USB cable; the computer will detect a **USB Mass Storage Device**

.. image:: /image/MYZR-SigmaStar系列/MYZR-SSD2355-EK199/烧录手册3.png
   :alt: 烧录手册3.png
   :width: 80%

| Double-click the flashing tool `USB_Factory_Tool_64_1.0.0.19.exe` as follows:

1. Detected device will be displayed
2. Select the firmware image to be flashed
3. Click the green button to start flashing
4. When progress reaches 100%, click the red stop button to finish
