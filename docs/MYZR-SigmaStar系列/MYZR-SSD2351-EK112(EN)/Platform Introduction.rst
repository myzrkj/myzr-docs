Platform Introduction
=====================

Product Overview
----------------

The SigmaStar SSD2351 is a system-on-chip (SoC) launched by SigmaStar Technology (China) for industrial AIoT and smart security applications. It is NOT a solid-state drive controller, which was a previous misunderstanding. Mass production began from 2024 to early 2025, primarily targeting industrial customers requiring long-term stable supply. The manufacturer commits to providing a continuous supply cycle of over 10 years.

Target Applications
-------------------

- Smart Vision: Face recognition, human detection, object tracking, motion detection
- Edge AI: Transformer network inference, smart cameras
- Industrial Control: HMI terminals, industrial displays
- IoT: Smart home, gateways
- Multimedia Devices: Audio/video processing, digital signage, display terminals

Key Features
------------

- High-performance CPU & AI capabilities: Quad-core Cortex-A35, 1.4GHz frequency, 0.5TOPS
- Video display & processing: MIPI DSI, TTL/RGB interfaces, supports 1080p+ displays
- Rich storage interfaces: SPI NOR/NAND, eMMC 5.0, TF card
- Multiple communication interfaces: Ethernet, USB, UART, SPI, I2C, PWM, GPIO
- Security features: AES/RSA/SM2/SM3/SM4 encryption, Secure Boot, OTP storage
