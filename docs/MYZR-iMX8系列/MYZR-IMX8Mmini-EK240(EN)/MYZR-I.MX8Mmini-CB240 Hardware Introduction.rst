Hardware Configuration
-------------------------

+---------+--------------+------------------+
| CPU     | i.MX 8M Mini | Quad Core        |
+---------+--------------+------------------+
| Memory  | DDR4 2GB     | Scalable to 4GB  |
+---------+--------------+------------------+
| Storage | eMMC 8GB     | Scalable to 16GB |
+---------+--------------+------------------+

**Power Supply**

- 3.3V, 5V input

**Working temperature**

- Commercial:

 | 0°C ~ 70°C

- Industrial:

 | -40°C ~ 85°C

**operating system support**

- Android
- Linux

Hardware Interface
----------------------

+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
| Interface specifications                | Maximum number of configurable interfaces | Description                                           |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
| Communication interface    | Ethernet   | 1                                         | 1 channel 10/100/1000Mbps Ethernet                    |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | USB        | 2                                         | 2 USB2.0 OTG interface                                |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | UART       | 4                                         | 4 UARTs, each up to 4.0Mbps                           |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | PCIe       | 1                                         | 1 PCIe Gen2.0                                         |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | I2C        | 4                                         | 4-channel I2C, up to 400 kbps                         |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | SPI        | 3                                         | 3 eCSPI (Enhanced CSPI), each up to 52Mbps            |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | PWM        | 4                                         | 4-channel 16-bit counter, 4x16 FIFO                   |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
| External storage interface | NAND       | 1                                         | 8-bit NAND flash memory                               |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | FlexSPI    | 1                                         | External serial port storage device                   |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | SD3.0/SDIO | 1                                         | EMMC version 5.1, SD/SDIO version 3.0                 |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
| Multimedia                 | DSI-MIPI   | 1                                         | 1 4-channel MIPI display interface, up to 1.5Gbps     |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | CSI-MIPI   | 1                                         | 1 4-channel MIPI camera interface, up to 1.5Gbps      |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | SAI        | 5                                         | 5CH I2S/SAI/AC97/TMD                                  |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
|                            | S/PDIF     | 1                                         | 1 S/PDIF stereo transceiver, support input and output |
+----------------------------+------------+-------------------------------------------+-------------------------------------------------------+
