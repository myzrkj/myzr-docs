MYZR-IMX8M-EVK 参数
---------------------

**处理器**

- i.MX 8MQuad
- 4x Arm Cortex-A53 @ 1.5 GHz
- Arm Cortex-M4 @ 266 MHz
- 1MB L2 缓存
- 浮点运算单元
- NEON

**GPU**

- OpenGL/ES 3.1
- OpenGL 3.0
- Vulkan
- OpenCL 1.2

**视频播放**

- 4Kp60高动态范围(h.265, VP9)
- 4Kp30 (h.264)
- 1080p60 (MPEG2、MPEG4p2、VC1、VP8、RV9、AVS/AVS+、h.263和DiVX)
- MJPEG - 8x8

**内存**

- DDR4 x32 2GB ~ 4GB

**存储器**

- eMMC 5.0 4GB ~ 16GB

**显示器/摄像头接头**

- HDMI 2.0a Type-A 接头
- MIPI-CSI Camera FPC接头
- MIPI-DSI Display FPC接头

**无线**

- 蓝牙 5.0
- Wi-Fi 802.11 a/b/g/n/ac MIMO 2x2
- 外部天线接头

**音频**

- 音频DAC 24位192kHz立体声
- DSD512
- HP插孔3.5毫米音频接头
- I2S/SAI
- S/PDIF Tx/Rx

**数据连接**

- 10/100/1000以太网
- USB 3.0 A型接头
- USB 3.0 C型接头
- USB 2.0 A型接头
- MicroSD接头
- Mini PCIe接头
- QSPI
- I2C
- GPIO

**调试**

- UART

**操作系统支持**

- Linux
- Android

**供电电压**

- 12V

**尺寸**

- 131mm x 100mm

**温度**

- 商业级 (0°C to 70°C Tj)

**生命周期**

- 2030+

**开发板器件**

- MYZR-IMX8M-CB300（核心板）一片
- MYZR-IMX8M-MB300（底板）一片
- 显示屏电路板一片
- 液晶显示屏一块
- 触摸屏一片

**开发板配件**

- 12V电源适配器1个
- USB下载线1条
- 网线1条
- 串口线1条

- 编译手册
