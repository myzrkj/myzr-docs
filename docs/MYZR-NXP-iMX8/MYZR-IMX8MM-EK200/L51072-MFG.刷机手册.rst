
刷机手册
========

下载文件
--------

　　打开网盘,下载 “uuu-5.10.72-imx8mm” 目录 “uuu-5.10.72-imx8mm.patch.*.zip” 压缩包。

解压文件
--------

　　解压 **uuu-5.10.72-imx8mm.patch.*.zip** 到 **uuu-5.10.72-imx8mm** 目录。

连接刷机线
----------

　　为开发板断电，用 USB 线连接开发板的刷机口（DOWNLOAD）和 PC。

拨码到刷机模式
--------------

| 　　把开发板的 “SW1” 拨到 *刷机模式*。

========== ========== ========== ========== ========== 
BOOT_MODE0 BOOT_MODE1 BOOT_MODE2 BOOT_MODE3 描述 
========== ========== ========== ========== ========== 
1          0          1          0          刷机模式
0          1          1          0          启动模式
========== ========== ========== ========== ========== 

| 　　注：拨码开关的ON (1) 是字母那一边，OFF (0) 是数字的那一边。

执行刷机
--------

　　给开发板上电，双击运行 “auto-myimx8mmek200-ucp.bat” 文件，这时候Windows 命令行窗口会看到如下信息：

::

   uuu (Universal Update Utility) for nxp imx chips –libuuu_1.2.135-0-gacaf035
   Success 0 Failure 0 1:32 ……

刷机完成
--------

　　刷机完成后，Windows 命令行窗口信息如下：

::

   uuu (Universal Update Utility) for nxp imx chips –
   libuuu_1.2.135-0-gacaf035 Success 1 Failure 0 1:32 24/24 [Done ] FBK:
   DONE 请按任意键继续. . .

启动开发板
----------

　　把开发板断电，“SW1” 拨到 *启动模式*，并为开发板上电，开发板即可正常启动
