+                             +-------------------------+-------------------------------+---------------------------------------------------------------------------------+
|                             | UART                    | 4                             | 4 channels of UART, each up to 4.0Mbps                                          |
+                             +-------------------------+-------------------------------+---------------------------------------------------------------------------------+
|                             | I2C                     | 4                             | 4 channels of I2C, supporting up to 400 kbps                                    |
+                             +-------------------------+-------------------------------+---------------------------------------------------------------------------------+
|                             | SPI                     | 3                             | 3 channels of eCSPI (Enhanced CSPI), each up to 52Mbps                          |
+                             +-------------------------+-------------------------------+---------------------------------------------------------------------------------+
|                             | PCIe                    | 1                             | Single-channel supporting PCIe Gen 3, dual-mode operation, which can be used as |
+                             +                         +                               +---------------------------------------------------------------------------------+

+                             +-------------------------+-------------------------------+---------------------------------------------------------------------------------+
|                             | QSPI                    | 4                             | 1 four-channel external serial flash device interface, supporting XIP mode      |
+-----------------------------+-------------------------+-------------------------------+---------------------------------------------------------------------------------+
| Multimedia                  | DSI (MIPI Interface)    | 1                             | 1 channel of 4-lane MIPI display interface,                                     |
+                             +                         +                               +---------------------------------------------------------------------------------+

+                             +-------------------------+-------------------------------+---------------------------------------------------------------------------------+
|                             | CSI (MIPI Interface)    | 2                             | 2 channels of 4-lane MIPI camera interfaces, supporting high-speed mode         |
+                             +                         +                               +---------------------------------------------------------------------------------+
|                             |                         |                               | (each lane up to 1.5Gbps), supporting 4K@30fps                                  |
