**Product Introduction:**

    -  **MYZR i.MX 8M Mini Development Board** (MYZR-IMX8MM-EK200) enables customers to easily evaluate the MYZR-IMX8MM-CB200 core board, providing a foundation and reference for customers to design their own hardware.
    -  **MYZR i.MX 8M Mini Core Board** (MYZR-IMX8MP-CB200) combines excellent processing capabilities with advanced audio, video and graphics functions, offering a high-performance solution suitable for embedded consumer and industrial applications.

**Target Applications:**

    - **General Human-Machine Interface (HMI) Solutions:** Implement touch control, voice, graphics, video, image analysis and visual functions.
    - **Streaming Video Devices:** Two-way video conferencing, video doorbells and surveillance, digital signage, machine visual inspection.
    - **Streaming Audio Devices:** Surround sound, wireless or networked speakers, soundbars, audio/video (AV) receivers, public address systems.
    - **Voice Control and Voice Assistants:** Suitable for home or noisy industrial environments.

**Key Features:**

    - **Multi-Core Processing:** 4 Cortex-A53 cores, each up to 1.8 GHz, delivering excellent system performance. This core complex adopts an advanced low-power manufacturing process, optimized for fanless operation with low heat dissipation system costs.
    - **GPU:** 3D GPU, 2D GPU.
    - **Display Interface:** 1 MIPI DSI (4-channel).
    - **Video Decoding:** 1080p60 VP9 Profile 0, 2 (10-bit) decoder, HEVC/H.265 decoder, AVC/H.264 Baseline, Main, High Profile decoder, VP8 decoder.
    - **Video Encoding:** 1080p60 AVC/H.264 encoder, VP8 encoder.
    - **Audio Interface:** SAI, PDM.
    - **Camera Interface:** 1 MIPI CSI (4-channel).
    - **Ethernet:** 1 Gigabit Ethernet.
